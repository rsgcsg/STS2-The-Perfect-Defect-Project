facts/lineage. Connector owns fair visible current/read/complete C/binding/revalidation/
delivery. Host owns isolated processes and exact lifecycle. Annotator owns native
witness/Source/Human correlation and immutable originals; Evidence owns integrity and
public terminal proofs. Policy Runtime owns model-neutral consumption/controller/
budgets/Stop, not strategy. Workbench/Hub own application tasks/permissions/artifacts;
STPD owns projection/TargetSpec/learning/evaluation. One repository and DLL do not
merge these authorities. H!=S, Commit!=S-prime, delivered!=effect, message!=N.

separately green producer/consumer tests, incomplete native presentation assumptions,
closure inventories, and source/package/install gaps let mismatches escape to real
integration. Distinct incidents were SDK cursor shape, expected-owner Await, map
travel timing, creature/card public-tip binding, known-stale intent policy, package
closure and original-report consumers. They are not evidence that one unchanged bug
was retried indefinitely or that the whole hard shell should be discarded.

The durable response is lowest-cost faithful producer/consumer/native examples,
exact identity and one existing owner per fact. Do not add another readiness manager,
legality engine, recovery ledger or UI workarounds. The lead's final documentation
size error is a separate process escape: review/check the assembled artifact, not only
its added paragraph. Existing 8KiB governance caught it correctly; its limit stays intact.

Program imitation remains useful as an integration/representation baseline. It does
