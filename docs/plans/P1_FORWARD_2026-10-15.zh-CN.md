## 1. 真实需求与协议目标

交付一个可以实际使用、独立检查并持续维护的全局 P1 系统：真实游戏和 Managed
提供相同声明版本的环境交互；程序、人工 P1 选择器和未来学习 Agent 使用相同协议；
环境记录能够转换为该协议，数据、分析、运行和工作台继续走既有上层链路。
普通战斗不能成为其他场景共同设计的前置，随机 Agent 早期死亡不能代替机制覆盖。

P1 定义信息、选择粒度、时序、反馈和失败语义。组件实现责任，SDK实现合同，
传输格式编码消息，Agent程序端口连接完整Agent，Model只是可选计算组件。
同一 JSON 或同一个文件名不证明协议意义一致；不为新协议另造控制、数据或任务权威。

- 尽量 Markov：每个决策先提供当前合法可取得的完整资料及影响后续机会的公开协议承诺；
  减少页面遮蔽造成的记忆负担，不提前读取未来结果，不宣称严格 Markov 或取消记忆。
- 向前：落实有意义的选择，代劳其唯一蕴含的机械步骤；有真实取舍的取消、撤选、时机、
  药水等机会仍须表达。只有一项不是强制证明。允许的不可撤回奖励拒绝必须有原生完成路径。
- 时序：合格决策边界→同边界完整信息与目录→实际取得/声明消费→选择→原生执行与机械步骤
  →下一选择或终局。子选择不能等父 Task 完成；Receipt、空目录、轮询和队列idle不独立证明后继。
- 记录：source事实、P1操作、Agent offer/consume/choice各守来源，能引用同一封存原件；
  Recorder不依赖Agent。原生Human捕获和P1人工选择器不可互称。格式不必叫P1，但原件须足够转换。

## 3. 采用与复用决定

保留Claude在PR188实现的一份SDK共享语义核心、两端原生绑定和可追溯的实际运行原件。
共享核心需修正完整性、实例关系、动作粒度、承诺和fold条件；其旧r1.0原件保持原身份。

复用现有：Native Foundation/LiveHost/NativeUi的事实和执行；Host Runtime的隔离/启动/关闭；
封存capture/Read；Policy Runtime的唯一控制、期限/Stop、Agent session、Evidence写入；
Annotator原生source记录；Evidence验证/Store/import；Workbench操作与数据目录。
独立runner中的有用逻辑迁入这些owner，CLI可保留为薄入口。旧ordinary-combat WIP只按实际
验证复用接线，不能把其未验收B结构或限定词当作全局前置。旧归档消费者和回滚资产保留。

比较优先复用已有C1的全字段/双射思想与测试，并提取真正共享的纯比较部分；
生产代码不反向依赖根tools。有损decision签名只能是诊断，不可作为完整等价结论。
图中同定义的两个实体仍是两个实例；选择、承诺、内容和关系必须在同一双射下比较。
未知字段按字面保留，语言/呈现差异仅按明确字段合同处理，歧义或不支持返回incomparable。

1. 复核提交的精确代码、原件和五项重点；保留可重复的反例与有用成功结果。
   代码基线be67e7a1、父ef79a994；所有修复在独立topic，原Claude提交不覆盖。
2. 并行修共享语义与已定位native缺口；先修正确性/完整性，禁止靠删字段/删机会凑通过。
   一位shared-interface writer，最多两位代码writer；一个heavy本机/native slot。
3. 把P1环境适配接入既有Runtime与Agent session；同时接原生capture/Recorder/Evidence。
   原环境事实能离线转换，实际Agent字节/消费/动作与原件可核，单个有用场景先贯通产品。
4. 用Reference原件派生记录驱动程序，在Managed当前目录中唯一重绑定同一P1意图；
   首分叉给具体字段/关系/机制，不继续把不同轨迹称同前缀。不传跨Host原生ID或操作数。
5. 目标机制覆盖补弱Agent遇不到的场景，再使用最终固定核心跑自然局套件和同机制配对；
   安排原生无Agent记录、转换、实际独立程序与产品UI路径各自的验收。
6. 冻结候选后运行所选完整门、exact-game和必要真实检查，非作者独立验收，
   最后逐PR请求merge/close批准。Human步骤只用于剩余Human命题，不让用户做自动化调试。

目标场景至少覆盖：普通/目标出牌、药水use/discard及目标域、EndTurn、生成/手牌/牌堆/

mandatory/decline、地图、事件、商店购买/移除/退出、营火、宝箱/遗物选择、跨幕、胜负和任务清理。

同seed只是对齐起点，不保证相同RNG/前缀。记录回放和自然策略suite互补，任何一项不代替另一项。
