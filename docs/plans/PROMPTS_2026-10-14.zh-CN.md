# 给本地 Agent 的 prompt（2026-10-14）

用法：把"通用开头"和某一段 prompt 一起复制给本地 Agent。它会把回复存到交接文件夹的 `replies/` 下，主管直接读取审查。
顺序与依赖：

| 阶段 | 可以同时发 | 前置条件 |
| --- | --- | --- |
| 0 | AUDIT-1 | 无（PR177 已合并，规则 PR 已开） |
| 1 | B、C、F（只读）+ D（写代码） | AUDIT-1 的修正已落地 |
| 1b | E | D 完成 |
| 2 | G、H、J（写代码） | C 完成（G）；B 完成（H）；J 随时可开始 |
| 3 | I（训练） | G、H、J 完成，用户确认第一轮配置 |
| 4 | 强化学习（另发） | I 完成 |
| 5 | K | I 有可用模型 |
| 随时 | Q（开放调查 / 审查 / 讨论） | 无 |

同时写代码的最多 2 个；只读的调查、审计、讨论不限。
