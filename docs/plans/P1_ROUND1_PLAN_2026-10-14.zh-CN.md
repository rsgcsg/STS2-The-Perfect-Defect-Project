## 2. 第一轮训练（行为克隆）

完整配置见 [P1_ROUND1_CONFIG](P1_ROUND1_CONFIG_2026-10-14.zh-CN.md)。要点：全部人类录制、全部角色；R1-A（现有 Structured M2 原样）和 R1-B（当前摘要 + 8 槽记忆 + ID 嵌入）；
超过 1000 步，在远端 GPU 上训练，所以训练引擎的批量化和 GPU 支持是关键路径。预计到 L1–L2。

## 3. 第二轮：强化学习（默认 GPU）

- 从第一轮最好的模型出发，在 Managed 上做 PPO：只在合法目录上打分，奖励 = 胜 +1、每层 +0.02，加对行为克隆策略的 KL 约束，防止一开始就学坏。
- 训练引擎需要先支持多局并行的批量训练（现在是单序列）。
- 环境放哪里是待决问题：Managed 目前只在 macOS arm64 上验证过。默认方案是把 Managed 搬到 Linux，在同一台云 GPU 机器上同时跑环境和学习器；
  在那之前可以先在 Mac 上用 24 个环境做小规模试跑。任务 J 先调查可行性和成本。
- 预算：本轮 GPU 上限 USD 20，第二轮第一次试跑在这个额度内；更大规模另行申请。

```text
阶段 3  I 训练 R1-A / R1-B → 导出、登记 → Managed 套件评测 → 真实游戏 ref-20 → SCOREBOARD

```

每个阶段的数字进 SCOREBOARD，决定进 DECISIONS。
