# Native structured M2 input, package and Agent

This is a new synthetic source/conformance instance, not a renamed S0 model or
native recording qualification. It uses native-logical-v1 directly and the
reviewed AgentSession protocol. Its source, InputSpec, projection, package and
inference-state identities differ from text-menu-v2/S0. No old data, weights or
training result are automatically admitted under the new identities.

`fullrun.native_structured_inputs` fixes the full-reference InputSpec. It takes
one complete native observation plus its complete SDK-verified ordered native
catalog. It checks the Connector binary catalog digest, count and public operand
bindings; it does not reconstruct legality or native operands. Persistent/page
public fields, actual status, all provided authorized referents and the current
public focus relationship form the observation graph. Offscreen/logically
available referents remain available despite visible:false. Native kind/role
strings remain source facts, rather than being forced into legacy entity/control
classes. Current public terminal/summary outcomes remain eligible.

Opaque declarations become reference edges, never identity embeddings. Transport,
clock, occurrence, control/receipt/history and private future-label subtrees are
excluded before declaration discovery. Current C is separately scored and never
enters the encoder/writer. Referential bags and equal-instance multiplicity are
retained; native declared order and native argument-role positions have explicit
meaning. Field/byte/node/edge/candidate bounds are declared in the InputSpec.
Model capacity failure rejects the whole input; nothing truncates or filters C.
The 10,000-member synthetic projection test proves binding/completeness, not
10,000-card neural performance or reachability.

`fullrun.structured_tree` is the shared pure typed tree/reference assembler.
The legacy wrapper retains its existing fields, filtering, selection and digest
semantics. `models.structured_weights` is the sole safe weight codec and exact
shape/parameter verifier, called by both package families. Both helpers are in
the reviewed legacy closures. Their introduction does not transfer old package
qualification across changed source identities.

`fullrun.native_structured_sequences` derives advances from the qualified native
occurrence tuple, with strict revision/coherence checks. New owner/focus or
A→B→A advances once even for equal features; repeated same-occurrence acquisition,
new lookup handles or same-capture pages do not. Empty C still consumes an
observation and advances W. Labels are optional exact catalog members; there is
no fake Wait label. Offline and online use the same projection/occurrence/reset
functions. The initial parser accepts synthetic sequences only. Real native
Actor/source bundles need the owning E2 verifier and exact captured/consumed
prefix bridge; legacy canonical rows cannot become native full-reference history
by changing a flag or schema.

`models.native_structured_scorer` stages Consume, then commits W and the actual
input/binding cache only after matching consume_ack. Unacknowledged state cannot
score, export or authorize Next. Explicit new continuity starts zero W; a changed
generation without that declared reset fails. The default Agent uses full-reference,
once-per-occurrence and handoff on gap. Independent receipts do not update W.

`policy.native_structured_export` creates a closed native package over the shared
weight verifier, fixed graph, InputSpec, source closure/lock and portable inference
ABI. Its current qualification is synthetic_engineering_only. The actual model
weight bytes and producer/data/training declarations remain separate identities;
standalone export does not attest that learning happened. Exporter platform is
provenance; inference requires exact Torch version including wheel suffix,
CPU/float32 and codec. The package contains no executable selection.

`policy.native_agent.bind_native_agent` binds a verified package to caller-owned
exact environment/support/seam facts and writes the fixed Agent Manifest.
`NativeStructuredAgent` implements Consume/Ack/Next and opaque state export/restore;
CLI arguments are `python -m stpd.policy.native_agent --package /ABS/package
--manifest /ABS/agent.json`. Static application registration and native Runtime
lifecycle remain their existing owners. The child neither acquires control nor
submits native actions itself. The programmed policy greedily selects from the
whole catalog or returns bounded Await for empty C. This timing policy is explicit,
not learned. A terminal status alone does not imply task completion or force Close.

State uses the existing safe tensor-tree codec with a 16 MiB bound, finite K1/d96
W, actual weight/InputSpec/profile/generation and durable acknowledgement prefix,
plus the last complete public input for exact score/binding replay. Runtime copies
opaque bytes and does not interpret W. Only a fresh child restores; bad metadata,
size/Base64/hash, missing scope/gap or wrong memory shape fails before committing
state. Restoring state never revives an action handle or clears unknown delivery.
The model validates its actual parameter bytes before consumption/Next/state copy.

Graph arithmetic is unchanged: shared byte CNN, one sparse relation layer,
entity-local aggregation and K1/d96 gated memory. Read attention over one memory
slot is identically one. N therefore reads the same global W for every candidate,
with candidate-specific kind/verb/label and current referenced entity gathers;
it is not query-selective multi-slot memory. Focus can affect current entity
relations and the writer, but no strength, learned timing, optimal teacher or
scientific quality is claimed. The next coherent learning step extends the existing
numerical engine/workload through an explicit trusted InputSpec profile; it does
not create another optimizer, trainer or operation journal.
