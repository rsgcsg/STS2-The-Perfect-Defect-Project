# Direct native sampled Agent admission

`stpd/fullrun/native_agent_sampled_source.py` consumes the public typed Evidence
verifier and preserves original Agent-run bytes. Its closed research relations
live in `stpd/native_agent_sampled_source_spec.py`. An accepted relation identifies
an exact original producer; it is not an alias for the current checkout.

The map-ready relation1.0.0 adds the original Teacher1.0.10/Agent1.6.0 artifact.
The earlier Teacher1.0.2,1.0.4,1.0.5 and1.0.6 tuples retain their frozen hashes,
policies, descriptors and single-runtime partition rule. No Teacher100 delivery
threshold determines whether a stopped original has useful targets.

The reviewed-segments relation and projection1.1.0 explicitly allow a train-only
partition over three archived producers: UTF-8 Teacher1.0.6/Agent1.2.0,
reward-ready Teacher1.0.8/Agent1.4.0 and map-ready Teacher1.0.10/Agent1.6.0.
Each artifact, adapter, input and execution policy must match its frozen
definition; absent policies are never reconstructed. Compatibility was reviewed
at the public complete Current/C, sampled consumption/ACK, script-state format,
student reexpression and exact delivered-handle N target boundaries. Timing and
private Teacher scripts differ and never become student memory or input labels.
Adding another producer requires another reviewed append-only contract.

Each original still contains one protocol runtime. Each projected run begins
with its original state1 ACK, null previous consumption and explicit segment
start; the student resets to W0 independently. Missing or unknown context
censors that original's continuous remainder. Aggregation cannot bridge it,
reconstruct a middle prefix or add a fake terminal summary. Original runtime
source groups remain intact. All offers, including readiness, rejected targets
and censored rows, retain exposure membership.

The aggregate adds the conservative association
`native-sampled-campaign:g2-v1-repeated-e6-start` to every original run and offer.
These runs reuse a campaign starting template. Runtime/run IDs do not establish
independent games, clean held-out splits, native game continuity or
statistical independence. This relation supports train only, with no dev/test
or Gold qualification. Exact duplicate evidence content and any cross-raw
reuse of an original `(runtime_instance_id, capture_id)` are rejected, including
aliases with different importer or run IDs; they cannot increase N.

N is the count of unique eligible original handle Act targets bound through
original offer/proposal/ACK/completed-Next/directive/submission/terminal Result
joins. Delivered results with native rejection, stale refusals, unlabelled
Await/Close and readiness offers do not become N. Known delivery, sample count,
N, native origin, Commit, causal successor, training permission and model
quality remain separate facts.

The public raw/admission/partition functions verify immutable originals again
on publication and replay. `LocalCurationOwner` reserves all original exposure
keys; explicit training-use recording remains a later action. Prepare and fit
through the existing native sampled source and recipe contracts after source
review, exact dataset selection and authorized use. This contract does not
start collection, train, register a model or upload originals.
