## 1. 一次决策究竟发生什么

假设当前有三个合法候选：“攻击左侧敌人”“使用防御牌”“结束回合”。模型分别产生三个分数，执行层把最高分对应的真实候选交给游戏。这里是机制例子，不涉及特定卡牌数值。

模型不生成原生命令，不猜动作 ID，不负责判定游戏是否合法。候选必须来自拥有相应权威的游戏与平台契约。当前公开可提交列表、完整语义合法集合及其适用边界要分别记录；不能把临时不可提交误当作游戏里没有合法动作。

记号如下。为避免目标 Z 与状态张量 Z 重名，**本文将当前内部状态统一写成 W，将候选后果表示写成 Y；大写 Z 只表示后继训练目标。**

| 记号／词 | 大白话 | 具体含义 |
|---|---|---|
| O_t | 现在能看到的资料 | 玩家当前依法可知的结构化观察，可能包括合法 Read 的结果 |
| A_t、a_i | 当前可执行菜单、其中一项 | 同一决策的真实候选集合及一个候选 |
| a*_t | 人类真正选的那项 | 行为示范，不是已证明唯一最优的动作 |
| O_next | 实际执行后看到的资料 | 经因果证据核验的下一个决策／终止边界；不必是下一回合 |
| E／T_BC／F | 读资料、处理资料的网络 | E 用于 A/D-Simple/D1；T_BC 是 B/C 的唯一主干；F 是 D2 的共享多遍主干 |
| token／embedding | 文本片段／片段的初始数字 | 初始查表不等于已经理解上下文 |
| latent／表示 | 网络的数字笔记 | 一个向量、一组 slots 或其他结构；坐标通常没有人工名字 |
| W／Y_i | 当前笔记／某候选的后果笔记 | 本次前向计算出的激活，不是整套网络的权重 |
| slot／query | 笔记位置／学会怎样取信息的初始查询 | 32 个 slots 可共同表示一份笔记，不代表 32 种未来 |
| head／读出头 | 将笔记翻译成答案的小网络 | 动作分数、血量预测、胜率是不同答案，需不同目标 |
| loss | 训练时的扣分规则 | 答错越多通常越大；梯度据此调整可训练参数 |
| checkpoint | 学会的处理规则 | 网络权重及相关训练身份；不同于某局运行时记忆 |

当前输入缺信息时先辨别原因：玩家现在能查到却没写入输入，应修输入；过去看见、现在看不见的事，用记忆；玩家从来不可能知道的随机结果，只能预测其条件统计。记忆不能恢复隐藏 RNG。

本文所有第一阶段游戏训练样本、真实动作、后继与结果均来自人类轨迹。通用预训练骨干包含外部先验，单独披露；不声称其预训练语料已审计为全人类来源。工程假数据可以查形状与边界，不能混入人类训练成绩。

## 2. 模型、变体、横轴，分别是什么

可以把模型结构理解成做题流程，把横轴理解成这套流程的训练和使用条件。

| 层级 | 回答的问题 | 例子 |
|---|---|---|
| 家族 | 先怎样组织信息，再怎样选动作 | A/B/C/D |
| 具体结构 | 明确有哪些网络、信息怎样流 | D-Simple、D1、D2 |
| 结构变体 | 同一结构中有哪种明确处理路径 | D2-2pass、D2-3pass |
| 四条横轴 | 网络来源、真实时间记忆、监督目标、表示约束 | PF、M1、N+Z-fact、R-VC |
| 配方与执行设置 | 具体多宽、多深、怎样读出和运行 | 384 维、32 slots、Linear、候选分块 |

横轴分开记录，有助于解释实验；不表示任意组合都无需改结构。例如给 A 加持续世界更新器，会形成需要单独定义的 recurrent/hybrid 图。D1 的两个核心独立、D2 的主干共享，已经是结构定义，不能作为隐藏开关随意互换名字。

### 2.1 四个家族和当前目录

| 名称 | 大白话处理流程 | 区别在哪里 |
|---|---|---|
| A | 把“局面＋一个动作”整份读完，直接打分 | 大读取骨干逐候选联合处理 |
| B | 局面、动作及动作读出位置交给一个 Transformer，直接评分 | 单主干、逐动作特殊位置读出；候选默认隔离 |
| C1 | 同一个 Transformer 为每个动作写一条后果摘要，再评分 | 与 B 单读出同图；预测含义来自后继目标与验证 |
| C2 | 同一个 Transformer 内放多个后果 tokens，再评分 | 增加读出位置，不默认增加第二个 Transformer 或独立 decoder |
| D-Simple | 先写公共的一条当前摘要，用 MLP 按动作修改 | 轻量向量转移 |
| D1 | 先写公共的多 slot 当前笔记，另一个 decoder 按动作修改 | 当前整理 C、动作更新 T 使用独立参数 |
| D2 | 同一主干先写当前笔记，再按动作修改；可再评估一遍 | 不设独立深层 E；共享 F，两遍／三遍 |

**七个设计名称不等于七个互不相同的在线计算图。** 当前 B/C1 同图；如果输入、读出、训练目标也相同，必须复用一个实验身份。按基础主体去重是六类；展开 D2 两遍／三遍后是七种基础结构方案。Linear/MLP、PF/PL、N/Z 不再各自增加家族数。

### 2.2 A：完整资料每个动作读一遍

```text
局面＋攻击 → 同一个 E → 摘要 → 小评分头 → 攻击分数
局面＋防御 → 同一个 E → 摘要 → 小评分头 → 防御分数
```

历史配方用 masked mean，即只平均有效 token；Qwen 摘要为 1024 维。评分头是 Linear，或 `1024→256→1` 的 GELU MLP。

A 的优点是接法最直接，也可能长期成为强策略。代价是当前实现重复读取长局面。mean 可能稀释动作差异，这是待检验的风险；末尾有效 token 是独立读出对照，要重新训练头。候选批处理提高利用率，不自动消除重复计算。

若只有 N，它学直接选择；加训练期后继辅助，不必改叫其他家族。要让辅助 loss 改善表示，必须有可训练的共享部分。例如 A-PF 可在可训练 MLP 隐层接辅助头；若仅在完全冻结的摘要上另训一个不共享的小头，只是在探测摘要，不能改变原评分器。

### 2.3 B 与 C1：一个 Transformer，从每个动作的特殊位置读答案

**B 的默认是单主干统一 token 处理，不是先经 E 再经 J。** 用 T_BC 表示这唯一的 Transformer；它可以有多层。观察和动作的词向量查表只是输入准备，不是另一个深层 encoder。

```text
共享当前观察 O
├─ 动作 a1 的内容；<ACT_READOUT> → h1 → 同一个 Linear → s1
├─ 动作 a2 的内容；<ACT_READOUT> → h2 → 同一个 Linear → s2
└─ 动作 a3 的内容；<ACT_READOUT> → h3 → 同一个 Linear → s3
           全部由同一套 T_BC 权重处理；分支间有 attention mask

独立分支的正确性参考：
X_i = [Embed(tokens(O)); Embed(tokens(a_i)); q_readout]
h_i = T_BC(X_i, causal_mask)[最后的读出位置]
s_i = Linear(d,1)(h_i)
```

大白话：每个动作后放一张“请总结这个动作”的小纸条。同一个处理者读局面、读这个动作，在纸条所在位置写一个向量，再把它翻译成分数。不同候选的纸条初始值相同，读到的动作不同，输出便可不同。不是给每个动作 ID 各造一个词，也不把候选编号输入模型。

09-10 原文用 `[ACT] … [/ACT] [SCORE]`，其中 `[SCORE]` 才是读出位置。这里的 `<ACT_READOUT>` 对应用户所说的动作 `<act>` 读出 token；它放在动作之后，不与动作开始分隔符混用。下列配方将它实现为独立可训练 soft query，直接拼接输入 embedding，不必扩展预训练 tokenizer 的词表。接口机制可参照 [Qwen3 的 inputs_embeds 文档](https://huggingface.co/docs/transformers/model_doc/qwen3#transformers.Qwen3Model.forward)；这不是现有 STPD 后端已经支持的声明。

默认 mask／位置合同：

1. 使用因果前缀：观察位置只读观察前缀，不读当前候选或读出位置。
2. 每个动作分支只读共享观察和本分支因果前缀；读出位置在本动作内容之后。隔离在每一层生效，阻止通过共享观察间接串扰。
3. 合并分支时，各分支的位置编号与单独输入 `[O;a_i;q]` 相同，不按它在候选列表中排第几个偏移；padding 与边界一致。仅设置普通整串 causal mask 不足以隔离多个候选。
4. 默认执行必须共享一次观察计算，全部候选分支和读出一起处理。独立分支只作诊断参考及旧产物复现，不作为新 B 的默认训练或部署。候选共享前缀后的输出与梯度，在 eval 关闭 dropout 时须与参考一致；scratch 训练共享前缀的 dropout，因此不承诺与旧执行逐步位级相同。

当前版本为 `b.shared-observation.v2`；`b.single-stream.v1` 保留旧逐候选实现及历史 checkpoint，不原地改义。物理执行可将冻结骨干分为“全部固定文本一次”和“全部读出一次”两阶段，这是同一逻辑序列的等价分解，不是两个 Transformer，也不重复按候选处理局面；S 使用一次完整 packed forward。PF/PL/RF 的宽度与层数继承所 pin 的骨干，参考 Qwen 为 1024 维；S 采用第 3 节唯一的两层、384 维主干。评分头统一为 Linear。PF 时 q_readout 与评分头可训练，骨干与原词表 embedding 冻结；q 在所有候选、样本之间共享。PF 的 q 起点复制固定 tokenizer 的 EOS embedding，具体 EOS ID、初值 digest 与 seed 记入 manifest；S 按锁定 seed 初始化 q。它是待验证的最小配方，不是已测最佳值。

C1 沿用相同输入和读出，将 `Y_i=h_i` 作为后果摘要；评分只读 Y_i。**相同参数化、初始化、mask、目标下，C1-N 就是 B-N，不重复注册。** 加 Z-fact 是同图多一道真实后继题，可写 `B/C1 + N+Z-fact`；辅助头只读真实执行分支的 Y，真实后继不进入在线主体。将特殊 token 改名为 FUTURE 本身不会让它会预测。

A 与 B 都可能只有一个主干；本文件的 A 基线是固定 joint mean＋MLP，B 是可训练特殊读出＋Linear。若某个 A 派生配方连输入、读出、mask、训练范围和目标都改得与 B 完全相同，它们也必须合并身份，不为了区分字母增加网络。

历史 E＋J 方案明确称为 `B-feature`；允许候选互读的版本明确称为 `B-Full`。两者均不是此处默认配方，不能在实现时静默替换。

### 2.4 C2：在同一个 Transformer 内增加后果 tokens

```text
X = [Embed(tokens(O)); 各动作的 (Embed(tokens(a_i)); q_1; …; q_K)]
Y_i = T_BC(X, 共享观察及候选隔离 mask)[动作 i 的后果位置]   # K×d
score_i = Linear(d,1)(Y_i[K-1])
```

**默认仍只有一个 T_BC，不额外接 J 或 FutureDecoder。** K 默认 32，宽度继承主干：参考 PF 为 1024，S 为 384。q_1…q_K 是有各自身份的可训练初始向量，所有动作复用同一组；每次决策重新使用，不是持久记忆。它们代表一份动作后果的容量，不是 32 个随机未来。

因果版本中，后面的后果位置能读前面的，前面的不能反读后面的；所以用**最后一个**后果位置汇总评分，不能沿用旧 decoder 的第 0 个 slot 规则后宣称它读到了后面全部笔记。训练期 Z-fact 也先读该末尾汇总位置。其他位置可通过后续层的 attention 影响末尾；有通路不保证模型真的利用了每张笔记。

C1 就是这一路径的 K=1。检验多位置是否有用时，固定主干、层数、mask 规则、head、数据、目标和优化协议，只比较 K=1／K=32；两组最后的汇总 query 采用同一初始化规则，额外 queries 按锁定 seed 初始化。记录新增 query 参数、位置变化、输入长度与计算成本，不把它称为完全等参数／等 FLOPs 实验。

C2 必须同样只放一份 O，一次得到所有动作的后果位置；每个动作的 K 个位置按固定顺序读取本动作内容和前面的后果位置，默认用最后一个评分。不能在候选循环中重新编码 O。C 的这个 packed 结构仍是设计定义，当前 1a 只实现 B 和 D-Simple，不能把 B 的测试当成 C 已实现。

第一个结构身份为 `c.single-stream.v1`，记录 K；K=1、N 与匹配的 B-N 共享实验身份。若以后让后果 tokens 双向互读，或者增加独立 query decoder，必须另立 mask／graph 版本。历史 `C-query-decoder` 只作为备选变体，不再是默认 C2。

### 2.5 D-Simple：公共一条摘要＋小更新器

```text
w = mean(E(局面))
u = mean(E(动作))
delta = MLP([w,u])
Y_a = L2Normalize(w + delta)
score_a = MLP_score(Y_a)
```

历史实现宽度 1024，更新 MLP 是 `2048→1024→1024`，评分 MLP 是 `1024→256→1`。它没有新增 decoder、slot resampler、VALUE attention 或 EMA 小目标网络。

大白话：先压出一条公共摘要，攻击和防御各自在它上面算修改版。更新器很轻，但前面的 E 仍可能昂贵；一条摘要也可能提前丢掉细节。

这正是当前 `S2SimpleScorer` 路线。历史 Z 使用冻结 E 编码真实后继，做归一化余弦距离监督，**不是原始向量的普通 MSE**。纯线性更新可作为以后一个算子对照，但当前默认是带非线性的 MLP。

### 2.6 D1：公共多张笔记＋独立整理与更新

```text
H_O = adapter(E(局面))
H_a = adapter(E(动作))
W   = C(Q_world, H_O)          # 当前公共笔记 32×384
Y_a = T(W, H_a)                # 这个动作的后果笔记
s_a = Linear(Y_a[0])
```

C/T 是两套参数独立、结构相同的两层 decoder。每层有 slot self-attention、读取外部条件的 cross-attention、FFN，以及内部残差。默认 384 维、6 heads、FFN 1536、Pre-LN、GELU、dropout 0.1、stack 末尾 LayerNorm；slot 内不按游戏时间做因果遮挡。

C 的条件资料是局面，T 的条件资料是动作。E 在两条读取路径共享。decoder 已有残差，不再额外套一层历史 S2-SDT 式外部残差。

大白话：整理员先写一本公共笔记；更新员拿不同动作分别改写副本；评分只读改完的笔记。好处是长局面只整理一次；风险是整理时尚未见到候选动作，可能漏掉某个罕见动作需要的事实。

严格 D1 不允许 T 或评分头绕过 W 再看完整原始局面。这里的“未来”仍是职责名称；N 单独训练只保证有动作评分信号，不能保证 Y 已是可靠世界预测。

### 2.7 D2：同一个主干做两遍或三遍

D2 没有单独的深层 E。tokenizer、embedding、位置／类型信息、小 bridge 都存在，但它们不另算一个深层阅读网络。

```text
D2-2pass：
第一遍：[当前观察输入；当前查询] → F → W
第二遍：[bridge(W)；动作输入；后果查询] → 同一个 F → Y_a
评分：  Linear(Y_a[-1])

D2-3pass：
前两遍同上
第三遍：[bridge(Y_a)；评分查询] → 同一个 F → r_a
评分：  Linear(r_a)
```

大白话：同一个处理者先读局面，再想一个动作的后果；三遍版本再专门审视后果一次。第三遍评估的是同一个动作，**不是又走了一步游戏**。

两遍有 n 个候选时，F 概念上调用 `1+n` 次；三遍为 `1+2n` 次。批处理可以减少调度开销，不把这些计算变没。共享参数减少独立权重，不保证训练更容易或运行更快。

因果主干的查询必须放在需要读取的资料之后；每遍的位置与 mask 要固定。第二遍只通过 W 获得局面信息；第三遍只读 Y_a。Z 优先接第二遍 Y_a；第三遍仍负责评分。两遍／三遍要分别训练。

D2 在本计划中仍为待实现与测量的设计。首轮第五子批固定 D2-2pass/PF：F 使用第 3 节相同 Qwen pin，W/Y 各 32 个查询、宽 1024；bridge 为逐 slot Linear(1024,1024)＋LayerNorm，只有一套；查询、bridge、Linear score 可训练，F 与原 embedding 冻结。所有查询置于相应内容之后，因果 mask；评分与辅助头均读第二遍的末尾后果位置，公式中的 Y_a[-1] 表示末尾后果位置。第一遍不看候选，第二遍不重读原始 O。queries 初始化按锁定 seed 与尺度登记，位置、阶段分隔、dtype 与序列布局在试跑前封存。三遍／S 等不在首轮这两格中。D1 对 D2 是系统比较，不是只改“共享权重”的纯单变量实验。

## 3. 第一条横轴：骨干从哪里来，训练哪些参数

这条轴作用于 A/D-Simple/D1 的 E、B/C 的唯一主干 T_BC，或 D2 的 F。Qwen 是候选实现，不定义家族，也不写进结构变体名称。

| 条件 | 大白话 | STPD 训练时更新什么 |
|---|---|---|
| PF：预训练冻结 | 骨干权重保持原样，训练明确声明的接口与小模块 | B/C 训练输入 queries 与 head；D1 训练 C/T 等；不能一概叫“只训练后面” |
| PL：预训练适配 | 保留原骨干，给它少量可学习改动 | 首配为 LoRA 与新增模块；不是全量微调 |
| RF：随机冻结对照 | 同架构随机初始化后锁住，只训练后面 | 用于判断预训练信息的价值；不是强 scratch 路线 |
| S：自建从头训练 | 自己的词表、embedding、小网络一起学 | 所有声明的模型参数；目标网络也不得暗藏 Qwen |

本轮将口语“打乱 Qwen”明确记为 RF：按同一 Qwen 配置重新随机初始化全部参数并冻结，tokenizer 保持不变；不指打乱输入文字，也不指逐层随机重排预训练权重。若要测字面意义的权重重排，须另设 Shuffle 配方，不与 RF 混称。S 则是小网络全部从头训练，不是随机冻结的大 Qwen，也不是从零训练完整 0.6B Qwen。

PF/RF 配对共享新增 query、head、adapter 等模块的初值与采样种子；B-RF 的 query 使用匹配 PF 的同一初值，不从随机 backbone 的 EOS 向量重新取值。RF 每个 seed 记录主干初始化 digest，配对报告仍包含初始化波动。PF 对 RF 可以在同架构、同输入等条件下诊断预训练权重的作用，RF 仍沿用预训练 tokenizer，不代表彻底无外部先验。PF 对 S 同时改变规模、架构、词表和初始化，回答的是两个完整系统的质量／成本，不是“只改预训练”的因果问题。

参考 PF pin 为 Qwen3-0.6B-Base，revision `da87bfb608c14b7cf20ba1ce41287e8de496c0cd`，hidden size 1024。换骨干要新锁权重、tokenizer、算子和精度。PL 候选起点为 q/k/v/o projections 上 rank 8、alpha 16、dropout 0.05 的 LoRA，状态与动作共用适配参数；这是待测配方。[LoRA 原始论文](https://arxiv.org/abs/2106.09685)

S 的词表只在 train 人类语料训练 byte-level BPE，目标 8192；embedding 宽 384，显式正弦位置。B/C-S 直接使用唯一的两层 Transformer 主干：6 heads、FFN 1536、Pre-LN、GELU、dropout 0.1、final LayerNorm，采用第 2.3 节因果／候选隔离规则，后面只接读出头；不再另加两层 J。D1-S 的两层文本 E 使用 padding mask 与自身固定的读取规则，再接 C/T，不能与 B 的单主干混称。输入事实、对象关系、数值不可因压缩而丢失。

B-S 的主要矩阵估算为词表 embedding 约 3.15M＋两层主干约 3.54M，约 6.69M 加 bias、norm、query 与 head 等；不再沿用旧 E＋J 的约 10.22M 估算。最终以实现枚举为准。B-PF-M0-N 的最小可训练部分只有一个 d 维 query 和 Linear(d,1)，d=1024 时为 2049 个参数（含 head bias）；不包含冻结主干，且参数少不保证反传便宜。

冻结权重不等于能关闭输入梯度。B/C-PF 的可训练 queries，以及 D2-PF 的 queries／bridge，位于冻结主干输入侧；须在正常 autograd 模式计算相关路径，loss 才能更新它们。不能把整个主干包在 no_grad／inference_mode 中或 detach 最终表示。骨干参数不累积梯度，与计算是否向输入传梯度是不同问题。[PyTorch autograd 官方说明](https://docs.pytorch.org/docs/stable/notes/autograd)

B/C-PF 默认不训练主干 attention/FFN，本轮检验的是冻结主干加可学习读出接口的能力；PL 才适配主干，S 才从头训练整个小主干。不能把 P03 称为“学会了全新的主干交互规则”。q 更新会改变 h，最终 h 不能跨训练更新作为固定特征缓存。只训固定 h 上的 head 是另一种 head-only 配方，也无法让 h 上的 R 更新表示。09-17 核读的 frozen-feature backend 不具备这里要求的输入梯度训练路径，需实际实现验证。

## 4. 第二条横轴 M：过去怎样进入下一次真实决策

### 4.1 M1 与 M2 最直接的区别

| 配置 | 大白话 | 下一次保留的东西 |
|---|---|---|
| M0 | 每次重新读当前资料 | 不保存局内模型状态 |
| M1：外挂记忆 | 每次重新做题，但带一本独立备忘录 | 独立的 m，例如 256 维 GRU hidden |
| M2：持续世界 | 一直维护同一本当前世界笔记，用新事实修订它 | 主体的 W 本身，可为向量或多 slots |

假设十步前看见一条后来无法查询的规则。M1 把它记在独立备忘录，下次做题时查阅；M2 让这条信息继续存在于当前世界笔记里，下一次直接在旧笔记基础上更新。

**区别是记忆在系统里承担的职责，不是向量对矩阵，也不是 GRU 对 Transformer。** M1 也可以用多 slots，M2 也可以只是一条向量。它们不构成必然越来越强的等级。

旧历史文本窗口 M1-H4 已撤下，不通过新名字恢复。训练 M1/M2 仍要读取连续真实序列；“取消历史窗口作为模型输入方案”不等于训练时不需要历史。

### 4.2 M1 怎样接入各家族

对 A/D-Simple/D1 等有独立 E 的结构，一个可比的 GRU 起点是：

```text
u_t = [当前观察摘要, 已确认的上一真实动作摘要, 边界标记]
m_t = GRU256(u_t, m_(t-1))
所有当前候选都读取同一个 m_t
```

| 主体 | 备忘录接在哪里 | 必须注意 |
|---|---|---|
| A | 投影 m 后与联合摘要拼接，再由同级 MLP 评分 | 观察摘要若另算，计入成本；head 变宽需匹配控制 |
| B/C1 | m 投影为 MEMORY 输入，进入唯一 T_BC 的候选共享前缀 | 不新增 E/J；具体更新时序见表后 |
| C2 | 同样把 MEMORY 放在唯一 T_BC 的共享前缀，后果 tokens 读取 | 所有候选读取同一份记忆，不接真实未来 |
| D-Simple | m 与观察摘要通过可训练融合层形成当前向量 | 仍先形成候选共享的当前表示 |
| D1 | m 作为 C 的额外条件 token | T 仍只通过 W 获取当前与历史信息 |
| D2 | 第一遍 F 读取旧 m、上一真实动作、当前观察，生成 W_t；GRU 再从 W_t 更新 m_t 供下次用 | 不为记忆另加深层 E；这是与上述先更新 m 不同的明确时序 |

B/C-M1 采用候选无关的两阶段时序，作为独立 M1 图登记：先由同一个 T_BC 读取 `[当前观察；已确认上一动作；OBS_SUMMARY]`，取摘要 e_t；GRU(e_t,m_(t-1)) 更新 m_t；再用同一个 T_BC 读取 `[MEMORY(m_t)；当前观察；候选；读出 tokens]` 评分。摘要调用与候选调用共享全部主干权重，不新增深层 E，额外调用计入成本。摘要阶段不看当前候选或当前选择标签，所有候选只读已更新的同一 m_t。训练需保留 GRU 与 MEMORY 投影的梯度；PF 时也可能需要穿过冻结主干。

M1-B 的 reset 控制：相同主干调用、GRU、当前观察和上一真实动作，但训练与推理每步都将旧 hidden 清零。它仍知道显式提供的上一动作；持续组比它多的是经过 hidden 留下的更早信息。只在训练好的记忆模型上突然清零，是扰动诊断，不是这组公平控制。

### 4.3 M2 怎样接入各家族

D1 的直接更新候选为：

```text
W_t = C(旧 W, [E(当前观察), E(已确认上一动作), 边界信息])
Y_(t,i) = T(W_t, E(候选_i))
```

这里 C 的初始输入由固定 Q_world 变成旧 W；新局才使用初始查询。C 必须在训练时见过这种输入。另一种 predict-correct 配方是先用已执行动作推进旧 W，再用新观察纠正；它是可选更新方式，不是 M2 必然多调用两次。

D2 第一遍直接读取“旧 W＋上一真实动作＋新观察”，仍由共享 F 形成新 W。D-Simple 需要一个新观察更新器维护向量。A/B/C 若要让主体状态跨步持续，就需明确定义 recurrent/hybrid 计算图；仅外挂一份旧摘要供参考，职责更接近 M1。

因此，M1 在大多数主体上接入相对直接；M2 在 D 上更自然。自然意味着信息流贴合，不意味着免费、不需新训练或必然更好。跨段传递连续 memory tokens 有已有研究先例，但本项目的真实决策边界与游戏证据仍须自行实现。[RMT 原始论文](https://arxiv.org/abs/2207.06881)

### 4.4 记忆怎样训练和在线使用

训练不能把每一步打散并从零开始。起步用 16 个真实决策的学习窗口，前置 8 步 burn-in 恢复状态；可将 32/16 作为后续比较。burn-in 是先读若干真实记录让记忆进入状态，通常不计主要 loss；窗口边界 detach 限制反传长度。有限 burn-in 不保证恢复整局所有历史。

在线时遵循同一时序：收到确认的新观察及上一已执行动作 → 更新一次正式记忆 → 用只读记忆评全部候选 → 执行选中候选 → 等真实证据进入下一边界。**试算攻击与试算防御不能各改一次正式记忆。**

新局清零；同事件不得重复吸收；恢复须绑定 run、模型 checkpoint、记忆格式与最后吸收事件位置。动作未确认时不能按模型“打算做什么”推进。模型权重是跨局学到的规则，m/W 是这一局的运行时数据，要分开保存。

评价记忆看事实出现距今 1/4/16/64 步时的表现、自然历史依赖案例及独立 reset 控制，不只看总体 Top-1。必须同时看记忆是否有用、是否串局、是否重复写入，以及实际序列训练成本。

## 5. 第三条横轴 L：用哪些真实答案教模型

L 只有三类任务：**N 学选择，Z 学近期后果，O 学指定终点的结果与有依据的偏好。** 它们可以组合，不是只能三选一的等级。

| 类别 | 大白话题目 | 答案从哪里来 | 默认怎样参与 |
|---|---|---|---|
| N | 当时人选了哪一项？ | 真实人类动作 | 所有首批模型的共同基础 |
| Z-fact | 这个动作以后，几个重要事实怎样了？ | 合格真实后继中的少量字段 | 可选辅助 |
| Z-latent | 能否预测真实后继的数字表示／统计特征？ | 目标编码器读取真实后继 | 可选辅助，须说明目标怎样训练 |
| O-predict | 从这一步继续，实际最后怎样了？ | 真实阶段或整局终点 | 可选结果预测辅助 |
| O-preference | 有充分可比证据时，哪种选择更符合目标？ | 经资格检查的结果比较 | 可选，直接训练动作分数 |

表里后四行分别是 Z、O 的子配方，不是额外四条横轴。历史配置名“Z”常意指 N+Z；本文写完整组合，避免 rank 被重复加两次。

### 5.1 N：人类选择题

```text
L_N = -log softmax(全部候选分数)[人类所选项]
```

大白话：人选攻击，模型却给攻击很低的相对分数，就扣分；提高攻击在这个候选集合中的相对分数，可以减少扣分。其他候选用于比较，不因此获得“坏动作”的真实标签。

如果同样已知信息下，人类有时攻击、有时防御，N 可以学到这种选择频率。它不必须判定其中一个错误，也不能仅凭分歧宣布数据冲突。先核查历史、候选与规则版本是否真的相同；画面相近不等于决策信息相同。

若另有多人标注的可接受动作集合，可单列多正例目标。不能利用封存测试标注反向改训练答案。

### 5.2 Z-fact：少量事实题，保持克制

初始只考虑下面这些事实，不手工穷举规则或把每个 latent 坐标写成人工属性。

| 字段 | 怎么定义才不会混淆 |
|---|---|
| 玩家血量 | 后继同一语义时点的 HP；缺失不填零 |
| 能量 | 只在有明确含义的决策界面监督；新回合刷新与出牌消耗区分 |
| 敌方血量 | 与具体敌人绑定；死亡且明确时可为零，消失／未知不直接当死亡 |
| 手牌数 | 后继可见手牌的数量，固定计数边界 |
| 卡组／牌堆数 | 总牌组、抽牌堆、弃牌堆分别定义，不能混叫一个 deck count |
| 层数／进度 | 固定版本与计数口径，不由日志行号推断 |
| 游戏结束 | 真正终局证据；记录中断、界面关闭不等于游戏失败或结束 |

人工工作主要是定义字段、适用界面和有效性；每条答案从合格轨迹自动提取。对象数量可变时使用带对象绑定与缺失 mask 的目标视图，不能让敌人列表重排改变“同一敌人”的标签。

首配连续标量用 train 尺度归一化后的 Huber loss；类别／结束标志用 CE/BCE。数值预测是点预测，类别头则自然输出概率。二者都属于 Z-fact；不再为类别概率重复命名 U。

**预测血量不等于奖励血量。** 网络可以被要求准确预测“花血买牌”，同时在人类选择或结果证据支持时给这个动作高分。Z 告诉它会发生什么，N/O 才提供选择方面的训练信号。

### 5.3 Z-latent：让真实后继自己变成数字答案

```text
候选表示 Y_a → 训练期读出 q → 预测后继特征
实际 O_next → 目标编码器 G → 真实后继特征
                         两边比较，产生 Z-latent loss
```

Z-fact 的答案有“血量”等人能读的名字；Z-latent 的答案由神经网络编码，可能包含对象关系、牌组组合等更广信息。**人工没有规定每一维的意思。** 是否真保存了这些信息，要用探针和预测检验。

有后果通路不代表有后果训练。一个模型即使中间张量名叫 future，只训练 N 时，也可能只学成方便排序的摘要。相反，历史 D-Simple-Z 已有这种监督，不是本轮新发明的功能。

目标编码器有三种不同训练合同：

| 目标更新方式 | 哪些部分怎样学 | 好处与风险 |
|---|---|---|
| 固定 G | G 不变；预测路径学着匹配它 | 答案稳定；G 已漏掉的信息无法补回 |
| EMA G | G 是学习中编码器的缓慢参数副本，目标分支不反传 | 降低目标剧烈变化；不自动保证非坍塌或语义正确 |
| 联合训练 G | 预测路径与真实状态编码路径共同更新；明确哪些梯度通过目标侧 | 能共同形成编码；也可能共同删除难预测信息或缩成常量 |

stop-gradient 只是“这条误差不更新目标侧”，不等于目标永远冻结；EMA 是权重更新方式，不是局内记忆。它们属于 Z 的目标更新配方，不占一条新横轴。

对联合方案，N、少量事实读出、当前状态的信息保持任务及 R 可以共同提供约束。任何约束都要有梯度通到实际需要学习的编码器。严格 S 不使用 Qwen 权重、tokenizer 或 teacher；若另预训练 G，只能用允许的 train 数据，并计入预算。

多 slots 对齐还须说明索引与布局：相同 query 身份可以规定对应位置，但不证明每个位置语义固定；来自不同网络的任意 slots 不可直接按行 MSE。首个新 latent 对照可读成固定维度摘要，明确 q 与 G 的输出空间，再研究整个 slot 集合的对齐。

有记忆时，别把整个 W 强迫贴近仅看当前 O 的 teacher；这可能惩罚历史信息。可令独立 q(W) 承担有限后继任务，或使用符合权限的历史条件目标，同时检验记忆是否仍在。

### 5.4 为什么额外题目可能帮助选动作

假设模型只记住某张牌名字，人类常选它，于是经常给它高分，却没学会判断能量与目标。

让同一份 Y 预测执行后能量和敌方血量：在不同费用、不同目标的例子中，抄卡名不再足够。答案错误产生梯度，推动形成 Y 的网络保留费用与目标关系；评分头随后有机会使用这些信息。

```text
当前合法信息＋候选 → 共享可训练表示 Y → 动作分数 → N
                                      ├→ 少量事实 → Z-fact
                                      ├→ 后继特征 → Z-latent
                                      └→ 阶段／整局结果 → O-predict
```

改变的是共享表示及相关网络的参数，不是运行时先看到真实未来再选动作。若辅助头接在 detach 的 Y 上，只更新辅助头，便没有这种改善主体的梯度路径。

帮助也不是必然的：模型可能把容量花在与选择无关的细节上，辅助梯度也可能和 N 冲突。所以必须比较同一主体的 N 与 N+Z、N+O，而不只报告辅助 loss 更低。

### 5.5 O：四项实际结果，严格区分预测与偏好

本轮 O 不再缩成胜负一个二分类。用户指定的四项结果为：**最终胜利、失败层数、战斗结束血量、主动打牌张数**。正式配方记为 `O-chain.v1`，同一份 Y 通过训练期结果头预测这些实际结果。不同标签可以有不同可用性。

| 标签 | 真实答案与资格 | 缺失／边界处理 |
|---|---|---|
| 最终胜利 | 已核验整局终点上的胜利／非胜利；失败、放弃等 disposition 单独保留 | 断录、直接关游戏、未知终局不填 0；放弃是否纳入非胜利先固定协议 |
| 失败层数 | 有真实失败终点时的失败位置，绑定游戏版本、Act／floor 口径 | 胜利时不适用；只知道当前层数不等于失败层数；放弃不擅自当原生失败 |
| 战斗结束血量 | 该动作所属战斗真实结束边界的 HP，附 max HP、战斗结果及其他资源上下文 | 整局未结束也可用；战斗未结束不能用最后观测 HP 冒充；胜战、死亡分别报告 |
| 主动打牌张数 | 从当前决策到本场真实战斗结束，已确认主动出牌的剩余次数 | 子选择、自动触发、日志行不是额外主动出牌；未知尾段不补 0 |

“最终不知道就看血量”落实为**分层可用的监督**：只有完整战斗、没有整局终点时，仍可训练战斗末 HP 和剩余出牌数；连战斗终点也未知时，继续使用合格的 N／Z。不是把未知胜负改成某个血量换算出的胜率。

四项都可以作为事实预测目标，但不意味着把血量最高或牌数最少的动作直接当最优。HP 比较必须有严格资格：进入同一战斗的可见配置、起始 HP／max HP、牌组与升级、遗物、药水、资源、难度、敌人、版本和相关合法历史一致；终点除 HP 外的重要资源、永久效果、收益／损失也须可比。不能把“喝掉药水剩 30 血”和“保留药水剩 28 血”自动排成前者更好。依赖低血量的机制也需协议说明，不能宣称血量具有无条件单调价值。

少出牌只在目标已达成、前面更重要结果相当、其他后果等价时作为效率偏好。快速死亡／提前放弃、少打有益的准备牌，不能靠“牌数少”得到奖励。计数事实可以在已结束的失败战斗上预测，但这不赋予它效率奖励资格。

偏好协议的意图是：**先看已知最终胜利；同为合格失败时比较有效进度；缺少终局时仅作局部战斗比较；严格可比时看 HP；更重要结果相当时才看出牌效率。** 局部偏好不等于对整局更优的证明。不写成随意的 `100×胜利＋10×层数＋血量－牌数`；训练 loss 权重是学习力度，不是这些价值的兑换率。

#### O-chain.v1 的固定训练配方

结果头只读当前实际执行分支的 Y 摘要，采用共享 `MLP(d→256,GELU)` 后四个独立标量读出：胜利用 BCE；失败层数与 HP 用 train 尺度归一化 Huber；出牌数用 softplus 保证非负后按 train 固定尺度计算 Huber。数值尺度与缺失 mask 写入目标视图；不按整个 test 建尺度。失败层数是条件于真实失败的目标，不能把其预测值对所有动作直接解释成综合进度价值。

为保留“终点还有哪些东西”的信息，另加 `O-end-latent`：采用第 10.2 节子批 B 同一个固定 Qwen teacher G，对真实战斗结束的合法观察编码；独立 `q_end(d→256→1024)` 预测其归一化摘要，计算 `1-cos`。终点序列化不拼入未来的整局结果；离线标签、teacher 和真实终点均不进入在线评分输入。相同终点只需编码一次。

```text
L_O = L_win + L_fail_floor + L_end_hp + L_remaining_plays + L_end_latent
L   = L_N + lambda_Z L_Z + lambda_O L_O                 # 首轮 lambda_O=1 起点
```

每项只在对应有效 mask 上算损失；先按独立局平衡整局目标、按独立战斗平衡战斗目标，再分别平均。没有标签的项为零并报告有效数量，不用零值伪标签。各项权重 1 是待试跑并在 dev 上冻结的起点，不是已经验证的最优设置；目标多的一项配方具有不同总梯度尺度，需披露。O-end-latent 是首轮 O 整体配方的一部分，不能把该配方的收益全部归因于 HP 或某一项。S 如后续接 O，不能暗中沿用这个 Qwen teacher。

Z-latent 教“下一个真实决策边界的摘要”，O-end-latent 教“本场战斗终点的摘要”，终点不同。恰好同一边界时，独立 head 的两个目标仍需披露重复监督；不能把它算成两份独立证据。latent 相似只能用于表示监督或检索候选比较对，**不能证明两场战斗条件等价**；仍用显式事实验证上述资格。

O-preference 是另一个可追加的直接动作损失：仅当同一个可比决策问题中，两个动作都有合格的真实轨迹结果、满足预先固定比较规则时，使用 `softplus(-(score(a_good)-score(a_other)))`。两个分数在同一输入／候选问题下重算，不比较不同局面的任意 logits。相同可见起点仍有随机结果和后续人类策略的混杂，单条胜负不能证明某动作的因果优势，需重复支持和不确定性分析。

**首轮 P16/P17 固定为上述结果预测包，不把尚未确认存在的偏好对假装成训练标签。** 在数据盘点后有足够严格偏好对时，追加独立 `+O-preference` 配置，每格三 seeds 另加 3 次；没有偏好对不阻止 O-predict 训练。部署仍用 N 的候选评分，改变为多目标结果直接排序须另立在线策略。单靠辅助头不保证选动作严格遵守以上价值优先级。

### 5.6 沿真实 s-a-s 链把 O 传回来

这里 s 是允许观察的状态与合法历史，不是隐藏完整状态。首轮采用真实轨迹离线标注，不用模型自己的预测充当目标。

```text
s0 --真实 a0--> s1 --真实 a1--> ... --> sb（战斗结束） ... --> sR（整局结束）
每步 N：学习人实际选的动作
每步 Z：预测下一真实边界的事实／latent
每步 O：有证据时继承该局终点胜负／失败位置；本场内继承 sb 的 HP／latent
剩余牌数：Cb=0，Ct=本边确认主动出牌数 + C(t+1)
```

例如从同一合格起点，两条真实轨迹都成功结束战斗、其余收益与损失相当；一条剩 30 血、一条剩 20 血，才有依据讨论局部保血偏好。若都剩 30 血、其他结果相同，分别主动出牌 4／6 次，才有依据讨论效率。未知整局胜负仍保持 unknown，不用局部结果伪造。

倒序扫描把已经观测到的终点标签传播到同一可证链的各起点。剩余牌数是当前以后，不含已经花掉的牌数；父动作与子选择不得重复计数。断链、未知因果边界、跨局、跨战斗的 HP／牌数都不能硬接。整局终点未被证明连接到某条片段时，也不能仅凭日志相邻补标签。

这属于用真实后续结果作监督／Monte Carlo 目标，**不是 TD/Bellman bootstrap**，也没有启动 RL。真实执行分支才有 Z/O；其他候选只有 N 的排序比较，不能给它们复制执行动作的终点。早期一步背后的结果也含后续人类选择，学到的是该行为分布下的条件结果，不是最优 Q。

多步潜在预测可另做 `T(...T(Z,a0),a1)...` 与真实中间／终点编码比较，但当前 O 不要求这条额外 imagined rollout。它需要明确 latent 闭合、真实动作边界、误差累积与额外计算，不能因 s-a-s 连续便认定已验证；不是为保留 O 而强制增加的第 23 格。

## 6. 原 U 放在哪里：一份表示怎样容纳不确定未来

### 6.1 一份 Y 可以表达多个可能后果

当前主线保留每个候选一份 Y。它可以代表“执行这个动作后，在现在已知条件下的后果统计”，不必等同某个真实世界的复刻，也不要求在线列出三条分支。

载体可以是向量、32×384 slots、原历史的 32×512，或实体集合。增加维度只增加可用空间，不自动决定存什么。普通 N 也可能学到有用风险信息，当前没有实验证据证明所有普通模型都已经发生有害平均。

原 U 的去向如下：

| 以前讨论的问题 | 现在放在哪里 |
|---|---|
| 下一步事件概率、几个字段的分布 | Z-fact 的分类／分布读出 |
| 普通后继 latent 的统计信息 | Z-latent 及其目标编码配方 |
| 更丰富的联合未来信息 | Z 的丰富特征、联合解码、对比或去噪候选 |
| 最终胜率、结果风险 | O 的结果预测及对应评估 |
| 采样、显式多分支未来 | 历史备选；不纳入当前默认在线主体 |
| 是否真的会表达概率 | 校准、分布区分、联合关系和动作利用的评估 |

### 6.2 普通平方误差究竟学什么

固定真实后继编码 G，令模型从已知条件 c 预测它：

```text
最小化 E[ ||q(Y(c)) - G(O_next)||² ]
总体最优：q(Y(c)) = E[G(O_next) | c]
```

这是对**固定目标、有限二阶矩、足够表达能力与总体最优**的结论。学到的是编码特征的条件均值，不一定是原始血量等物理量的平均；若只约束 q(Y)，也不意味着整个 Y 只能含这些均值。

一个会碰撞的例子：三种后果编码为 0、1、2。“0/2 各一半”和“必然 1”都平均成 1。更多数据可以更准确地学到这个 1，却不能让同一个 1 同时告诉读出器两种不同风险。

一个不碰撞的有限例子：三个编码分别是 `(0,0)`、`(1,0)`、`(0,1)`。按概率平均得到 `(p_B,p_C)`，另一个概率为 `1-p_B-p_C`。这次平均保留了全部三个概率。

这些手写数字只演示条件，不要求给游戏人工编码。一般而言，从已知 M 个固定编码的均值唯一恢复任意混合概率，需要它们仿射独立，维度至少 M−1，还要数值稳定。**编码彼此不同，比混合以后不冲突弱得多。** 有限维均值嵌入的条件也不能泛化成“所有神经分布表示都必须列出全部状态”。

### 6.3 我们的编码器也一起训练，会不会自己长出来

可以形成有用结构；需要明确是什么迫使它保存这些区别。

假设两种局面被编码成同一个 Y，但它们的正确人类选择不同。若评分器只看 Y，它不能分别答对，两类 N 样本会推动网络区分它们。若两种局面人类都选同一动作，N 就未必要求保留后果风险的差异。

同样，联合训练的 G 若把很多后继编码成同一常量，预测误差可以很小。N 能阻止一部分与选择冲突的坍塌，却不会自动保护所有随机后果。R 可阻止整体信息退化，Z/O 则告诉网络哪些预测差别与任务有关。

每条记录的过程是：

1. 当前合法信息和动作经过网络，生成 Y。
2. 从 Y 得到动作分数与所启用的预测答案。
3. 用实际人类选择、真实后继和实际终点判错。
4. 误差从各读出头穿过 Y，回传到形成它的网络；按合同也可更新后继编码器。
5. 更新权重；下一条样本用新权重重新生成表示。

**长出来的是“怎样组织信息的规则”，不是所有样本共同覆盖的一张全局矩阵。** 当前矩阵是这些规则对本次输入算出的结果。M2 跨决策保留它，是另一件需要专门训练的事。

### 6.4 怎样更直接地让“丢掉概率结构”付出代价

一个机制清楚的候选是**训练期后继解码器**。它只能通过 Y 获得当前条件，预测实际后继；在线可以移除它。

先用三种后果讲原理：真实 A 样本的扣分是 `-log q_A`，B/C 同理。若真实频率为 0.5/0.3/0.2，总体扣分为 `-0.5 log q_A -0.3 log q_B -0.2 log q_C`，在概率输出族足够时，最优就是该分布。每条样本只给实际发生的结果，无需预先提供真实概率表。

若两个条件的后果分布不同，却生成同一个 Y，只看 Y 的读出器只能给同样答案；在理想表达与优化条件下，分开编码可降低损失。这给表示提供了保留差别的压力。概率损失的总体依据可见严格适当评分规则研究；有限数据、模型错设及联合目标权重仍限制实际效果。[Gneiting 与 Raftery，2007](https://sites.stat.washington.edu/people/raftery/Research/PDF/Gneiting2007jasa.pdf)

真实游戏不用枚举完整 A/B/C 世界。可以按固定合法字段／实体序列建联合解码器，让每个字段根据 Y 与此前字段预测，组合为联合似然。训练时真实后继前缀只进入辅助解码器，不能流入 Y 或在线评分。若解码器另读原始 O 绕过 Y，就不能据此说 Y 保留了信息。

仅分别预测血量分布和能量分布，仍可能漏掉它们的关联：高血高能／低血低能各半，与高血低能／低血高能各半，两个边缘分布相同，联合关系相反。要要求区分，就需要联合目标或足够丰富的联合特征。

### 6.5 现在保留哪些 Z 研究配方

| 配方 | 大白话 | 主要边界 |
|---|---|---|
| 普通 Z-fact | 把几道关键事实题答好 | 不保证完整世界／联合分布；首批采用 |
| 普通 Z-latent | 预测神经网络写出的后继笔记 | 必须交代 target 更新与信息保持；普通余弦不直接等于均值学习 |
| 丰富特征均值 | 对同一后继编码做固定非线性变换，再回归其期望 | 不人工枚举全部关系；有限特征仍有盲区；固定线性变换不能凭空补高阶信息 |
| 训练期联合解码 | 让 Y 足以预测实际后继的联合结构 | 监督依据直接，增加训练成本；容易内容可能主导 loss |
| 对比预测 | 判断当前条件与真实后继有多相配 | 负例采样影响所学内容；配对分数不是现成概率 |
| 条件去噪 | 用 Y 帮助恢复不同噪声程度的真实后继 | 平方误差的预测对象已变，不能当成普通一步均值回归；成本更高 |

对比预测、去噪有原始机制参考；这里把它们作为 Y 的训练期任务是项目候选，不是已证明适合本项目的配方。[CPC](https://arxiv.org/abs/1807.03748)、[DDPM](https://arxiv.org/abs/2006.11239)

不用同时启用整张表。先测普通目标；当同均值不同风险、联合关系或动作敏感性确实不足时，在固定主体上比较一种更强的 Z。删去显式未来分支不代表必须禁止所有训练期概率读出。

### 6.6 数据、容量、双下降，分别能做什么

更多数据增加覆盖、减少统计误差；更多维度增加容量；优化方式影响实际找到哪种表示。它们都有价值，但都不能给一个完全不计较某项区别的目标自动补上保证。

双下降讨论误差随容量／训练进程的非单调变化；它不是多种未来结构自动出现的机制。[原始研究](https://arxiv.org/abs/1912.02292) 隐式正则化可以影响优化偏好，但当前不能据此保证 STPD 保存未受监督的重要后果。没有本项目的容量曲线，就不声称已观察到双下降。

目标是学到可检验、可利用的组织方式，不要求每行对应一种未来、每维都有人工语义。换一种可逆坐标，信息仍可能完整。能区分真实后果分布、能被读出、能帮助选动作，要分别检查。

## 7. 第四条横轴 R：防止表示偷懒，但不指定它必须写成什么

### 7.1 R 可以整体使用，不只属于世界预测

R 的定位是**可用于各家族的表示正则**。N+R 是有效配置，未必有 Z；M1 的记忆、B 的联合摘要、D 的当前笔记，都可以成为作用位置。

“整体使用”的准确含义是统一一套选择与记录规则，允许不同模块使用；不是给所有中间层、最终分数和概率输出一律加同一项。

| 条件 | 大白话 | 当前位置 |
|---|---|---|
| R0 | 不加专门表示防坍塌项 | 必备基线；仍可有正常 weight decay、dropout |
| R-VC | 不让各样本的表示挤成一样，也减少不同维度重复记同一件事 | 首个受控候选 |
| R-SIG | 在随机方向上约束表示的整体统计形状 | 后续替代配方，不默认与 R-VC 叠加 |

R-VC 借鉴 VICReg 的方差与协方差项；这里没有直接照搬它完整的双视图图像训练，也不把名字当成项目效果证明。[VICReg](https://arxiv.org/html/2105.04906v3) LeWorldModel 则提供联合训练编码器与预测器、配合 Gaussian 正则的研究实例；它不保证任意游戏的随机后果都可完整解码。[LeWorldModel，v1](https://arxiv.org/html/2603.19312v1)

### 7.2 两项约束分别在管什么

方差项：看一批不同真实样本。如果某个被约束的坐标几乎总写同一个数，就增加扣分，鼓励它随输入变化。

协方差项：如果多个坐标总以高度重复的方式一起变化，就增加扣分，减少冗余。

它们没有规定第 1 维写血量、第 2 维写能量，也没有要求不同状态全部正交。必要的信息共享仍由任务和权重权衡。正则太强可能制造无关差异、损害真正有用的压缩。

R 不能保证语义正确。网络记住 run ID 或无关格式，也能让表示看起来分散，所以这些身份捷径本来就不应进入模型。有效秩高，也不代表记住了随机后果概率。

### 7.3 加在哪里才有意义

| 位置 | 可以怎样用 | 边界 |
|---|---|---|
| A | 可训练评分 MLP 的共享隐层 | 冻结 E 上单独加 R 不会更新它 |
| B/C1 | 唯一 T_BC 的动作读出 h／Y | PF 的 R 经主干更新 query，PL/S 还更新声明的主干参数；不得 detach |
| C2 | 同一主干内后果 tokens 的末尾汇总／明确展平表示 | 不把 tokens 当作独立数据样本；作用位置单独固定 |
| D-Simple | 可训练更新后向量，或新增可训练当前映射 | 历史 PF 当前 pooled 向量固定，R 对它无训练作用 |
| D1 | 可训练 C 形成的当前 W | 对实际状态编码施加约束；另验预测 Y 的性质 |
| D2 | 第一遍 W；需要时明确第二遍 Y 的单独配方 | 梯度作用于共享 F／可训练接口 |
| M1/M2 | 记忆 m 或持续 W | 不能为了方差强迫记住无关历史 |

预测 Y 若表达条件均值，其跨条件方差可能天然小于实际后继编码方差。不能不加区别地把两者强迫成同一统计分布。最终分数、胜率概率也不应为“防坍塌”被硬拉开：某些动作确实等价，概率本来也可能接近。

### 7.4 首个可执行候选：R-VC-sketch16-v1

为避免一上来估计上万维完整协方差，首个试跑采用下面这套**新建议配方**，不是现有实现或文献原样复现：

1. 每个真实决策取一份表示 h。B 取人类已执行分支的特殊读出 h；D1 取当前 W 展平后的向量。两者分别做 R0/R 对照，不宣称作用位置完全相同。
2. 用固定 seed 生成、行正交且单位范数的线性投影 P，将 h 投到 16 维 x。P 不训练，也不编码人工语义。固定投影只能约束所观察的子空间，其他维度仍可能退化。
3. 每个统计 batch 至少包含 32 条不同真实决策，尽量来自不同局；记录局数与采样政策。候选数与 slot 数不增加独立决策数量。
4. 计算各坐标跨样本标准差和样本协方差：`R_var=mean(max(0,1-sqrt(var(x)+1e-4)))`；`R_cov=sum(offdiag(Cov(x))²)/16`。
5. 起点 `R=R_var+R_cov`，总损失系数 `lambda_R=0.1`。这是公开试跑值，先检查与任务梯度尺度的关系；正式比较前冻结，不能按 test 或每个 seed 单独选最优系数。

R0 使用同一网络、样本组织与训练协议，系数为零，不因多一个可训练投影而改变容量。统计应在一次可微计算中形成；普通梯度累积并不自动等价于一个更大的 R 统计 batch。显存不够时，要实现正确重算／统计方案，或在正式实验前改版，不能用脱离梯度的旧缓存冒充相同正则。

16 维投影仍可能掩盖退化，故完整 h 的方差、有效秩、语义探针仍要报告。LayerNorm 只约束单样本坐标，不证明跨样本不坍塌；固定 slots 身份带来的样本内差异也不算跨局信息。

### 7.5 R 与 L 怎样一起写

```text
L_total = L_N
        + lambda_f L_Zfact
        + lambda_z L_Zlatent
        + lambda_o L_Opredict
        + lambda_p L_Opreference
        + lambda_r R
```

没有启用的项系数为零。L 决定答哪些题；R 决定内部表示受到什么额外约束。R 在数学上也是总 loss 的一部分，独立成实验轴是为了跨模型、跨任务清楚比较。

非坍塌、事实可读、分布可区分、动作有效、可连续推演，是五件需要分别验证的事。对 R 的预期应是帮助学习，不能把任何非零方差当作后四项的证明。

## 8. 把四条横轴接起来：训练与实际使用的完整过程

### 8.1 以 D1 / S / M1 / N+Z-fact+O-predict / R-VC 为例

这是用来解释组合的示例，不表示首批立即训练这一整套。

1. **准备资料。** 从合格人类轨迹读取当前观察、完整适用候选、上一确认动作及序列边界；真实后继和终点标签放在另一条训练目标通路。
2. **读取。** 自建 E 读取状态和动作，参数可训练。GRU 根据真实序列更新 m，供 C 使用。
3. **形成公共当前笔记。** C 从当前观察资料与 m 生成 W。它不接当前人类所选动作标签，也不接真实未来。
4. **试算候选。** 每个候选从同一 W 出发，经 T 得到 Y_i，再打分。所有候选相互隔离。
5. **算选择题。** 全部候选分数和人类选择计算 N。
6. **算后果、结果题。** 只取真实执行动作对应的 Y，预测可用的后继字段与终点结果。缺哪个标签就屏蔽哪一项，不填零、不删除它本来有效的 N。
7. **算表示约束。** 对一批不同真实决策的 W 计算 R。R 不需要后继标签。
8. **一起反传。** 合并损失，更新 E、GRU、C、T、评分头及启用的辅助头。梯度范围由这些部件的实际连接决定。
9. **下一真实决策。** 用确认动作和新观察继续序列；跨局清零、窗口边界按协议 detach。

换成 PF 后，E 参数不更新，其他可训练部分仍共同学；换成 M0 后没有 GRU 与跨步 hidden；换成 M2 后由 W 自己持续更新；关闭 Z/O 后不需要这些训练期读出和标签。

部署时只执行第 1 步里的合法当前信息与记忆路径，再做第 2–4 步和真实执行。真实后继／终局答案、训练目标网络和不用来选动作的辅助头都可以不部署。学到的影响已保存在主体权重中。

### 8.2 训练样本最少需要哪些合同

| 视图 | 必要内容 | 不允许的替代 |
|---|---|---|
| DecisionView | run／decision 身份、合法观察、适用候选、真实人类选择、可见性版本 | 用 LLM 猜动作、用候选序号当策略信息 |
| SuccessorView | 真实执行见证、确切因果后继、目标字段与缺失 mask | 按相邻日志行配对；将 Commit 当作状态 |
| OutcomeView | 同局／同战斗真实因果链、四项 O 与独立 masks、终点合法 latent、比较资格、截尾状态 | 未完结填失败；最后 HP 冒充战斗末 HP；为未选动作补终点 |
| SequenceView | 时间顺序、上一确认动作、reset、burn-in、有效步 mask、恢复位置 | 随机打散后从零训练却声称有记忆 |
| RepresentationView | serializer／tokenizer／事实覆盖、对象绑定与位置类型 | 只给 pooled features 却声称能训练 token core |

同一局及其重复导出、回放、近重复来源必须属于同一数据关联组。先按组划分，再做输入、标签和序列；tokenizer、尺度、采样统计只从 train 学。未来可进入训练标签，不能进入当时的评分输入或过去记忆。

**目标缺失 mask 不放宽源数据准入。** 完整局与合格片段是不同合同：不能先删除坏行，再将剩余部分称为合格完整局；片段必须走实际仓库拥有的独立版本化准入入口，不能从 complete Full-Run 的 `admit` 推断其资格。本文说“保留有效 N、屏蔽缺失 Z/O”，只指已满足相应完整局或片段合同的样本。09-17 的实现快照不能决定后续仓库是否已增加片段通路，实际使用时查当前 owner 源码。

### 8.3 哪些设置仍要记录，但不再扩成主要横轴

| 设置组 | 要固定的内容 |
|---|---|
| 输入 | 合法事实集合、serializer、tokenizer、数值和实体编码、最大长度及截断规则 |
| 容量与 block | 宽度、深度、heads、slots、位置、mask、归一化、FFN、参数共享边界 |
| 读出 | mean／末尾有效 token／汇总 slot，Linear／MLP，以及辅助头接入位置 |
| 多步诊断 | 推演步数 1/2/4，后续动作从哪里来，是否每步获得真实观察 |
| 训练与执行 | 优化器、batch、seed、预算、早停；硬件、精度、候选分块、cache、kernel |

结构化实体输入是值得保留的后续方向：用玩家、敌人、卡牌等对象及关系组织资料，减少标点和字段名开销。但它可能改变信息组织与归纳偏置，应注册明确输入配方，不称为免费的 tokenizer 优化。

只要数值语义保持在声明容差内，纯执行缓存可归于同 checkpoint 的 runtime 配置。换 pooling、语义 mask、输入事实或训练精度不能隐去差异。A 前缀缓存还要求 token 前缀、位置、mask、权重一致；保持旧 mean 等价须保留前缀隐藏和及长度，不能只复用 KV 就假定完全等价。

完整身份至少为：

```text
plan_version + graph_version + structural_variant
+ backbone/tokenizer/initialization/train_scope
+ M(layout, update, reset) + L(targets, weights, target_update)
+ R(method, location, scale, statistics_batch)
+ input/shape/readout + dataset/split + optimizer/budget/seed + source identity
```

旧 checkpoint 不因显示名改变而原地改义。例子 `D1 / PF / M0 / N+Z-fact / R0` 已能解释研究问题，但还不是足以重跑的全部身份。

## 10. 后续完整研究：22 配置具体做什么

### 10.1 先完成共同准备，不直接启动模型大赛

先产出一份真实数据报告：合格局数、玩家／版本／角色覆盖、有效决策数、候选数、可用后继比例、各事实字段覆盖、完整阶段／终局比例、连续序列长度。100 局不能直接乘一个假定步数当作样本库存。

同时测真实 tokenizer 长度 p50/p95/p99/max、长输入是否截断、各配方可合法缓存的字节数（B/C 可训练 query 的最终 h 不属于固定缓存）、前向／反向峰值与候选数分布。先有这些数，再估训练工期。单卡 24GB 是容量条件，不是“肯定几小时跑完”的依据。

数据准入通过后，按整局及泄漏关联组，暂以 70/15/15 分 train/dev/test。若关联组太大或样本太少，记录实际比例与覆盖，不破坏分组凑比例。test 封存；第一批内部筛查只用 dev，最终候选与协议冻结后统一评 test。

以下为后续研究路线，当前任务仅按 STAGE1A 执行，不自动启动全部历史实验。研究实施顺序是：共同 Decision/Successor 视图与分组 → A/D-Simple 基线、单主干 B、D1 与四种骨干条件 → Z-fact／Z-latent → OutcomeView 与 O → R → D2 两遍通路。只在各自数据和实现条件满足时运行对应子批；不是等一个模型宣布获胜才继续。所有子批共用封存协议和数据划分，前批基线直接复用，不重复计数。

### 10.2 完整研究清单：五个子批、22 个配置

当前计划身份为 `stpd.four-axes.human.v2026-09-18.outcome-chain.v3`，配置编号改为 P01–P22。全部 M0，不做 RL，不加在线随机未来分支；未写 R 的行均为 R0。每个子批检验一组问题，不能在结果出来前称为“已证明”。

Z-latent 正式进入首轮，D 系列为主要对象。以下 N 基线直接复用子批 A；新增配置从匹配初始化独立训练，不能无说明地在已训 N checkpoint 上继续训练后称为同预算配对。

| ID | 主体 | 骨干 | 目标 | 对应基线／问题 |
|---|---|---|---|---|
| P11 | D-Simple | PF | N+Z-latent-fixed | P02：公共向量能否从后继表示学习中受益 |
| P12 | D1 | PF | N+Z-fact | P07：少量可核查事实题是否有用 |
| P13 | D1 | PF | N+Z-latent-fixed | P07：后继表示题是否有用；P12：目标配方比较 |

Z-latent-fixed 在本轮是一个固定、可复核的具体配方：

- 目标 G 使用第 3 节 pin 的**冻结预训练 Qwen**，对合法真实 O_next 做 masked mean，并 L2 归一化，得到 1024 维目标 g。G 的 tokenizer、serializer、截断、mask、精度与 digest 固定；不按策略 checkpoint 改变。
- 各主体从真实执行动作的 Y 接相同形式的辅助读出 `q: d→256→1024`，GELU，输出归一化；损失为 `1-cos(q(Y),g)`，lambda_z=1 是试跑起点。D-Simple 读其更新后向量，D1 读第 0 个后果 slot，B/C1 读动作特殊位置，D2 读末尾后果位置。
- 对每个 N／N+Z 配对，辅助模块配置与初值相同，N 侧仅将相应系数设零；在线评分图不变。额外计算与训练参数分别报告，不把训练成本说成相同。
- G 不反传、不 EMA、不与学生共同更新；PF 时可复用完全相同的冻结 Qwen 编码模块，PL 时目标仍是适配前的冻结 G，不能偷偷跟着 LoRA 改动。目标可预计算并按身份缓存，其磁盘、编码和额外常驻权重成本计入总账。
- 同一排序样本集合中只有真实执行且后继合格的动作计算 Z；缺失保持 N。归一化 epsilon、零向量处置、终止观察可用性、目标覆盖在 manifest 中固定。R 不保证 frozen G 已保留全部语义，先检查目标是否非退化及事实可读性。

这是后继表征蒸馏／预测的第一组受控试验，不是联合学习 G 的实验，不以余弦损失低证明世界预测完整。P11 也不是原历史 S2-Simple 目标接法的原样复现：本次有统一辅助 q 与新版身份，不能直接套旧结果。

**S 严格不用 Qwen teacher。** 本子批不将上述 G 接到 P06/P10；S 的 Z-latent 联合／自监督目标另见第 11.2 节的四格配对。不能为凑满四种骨干的 Z 表偷偷破坏 no-Qwen 声明。

本子批累计 15 个配置；三 seeds 累计 45 次。

### 10.3 哪些是同一个主体的配置，究竟数什么

| 主体设计 | 本轮配置 | 数量 |
|---|---|---|
| A | P01 | 1 |
| B/C1 单主干 K=1 | P03/P04/P05/P06/P15/P18 | 6 |
| D-Simple | P02/P11 | 2 |
| D1 | P07/P08/P09/P10/P12/P13/P14/P16/P17/P19/P20 | 11 |
| D2-2pass | P21/P22 | 2 |
| 合计 | 五种主体设计，22 个配置 | 22 |

这里“五种”按主体信息流模板计，不是说 PF 与 S 的每层结构相同：S 会更换主干规模／词表，PL 会增加 LoRA，训练期 Z/O 会加辅助读出。PF/RF/PL、S、N/Z/O/R 都要记录完整配置身份；相同在线主体也可能有不同训练图。C1 的 P15 是 B 的同主体后继配置，不多算一个新主体。不同 seed 是同配置的独立训练重复，会生成不同 checkpoint。

因此完整执行是 **5 种主体设计 → 22 个实验配置 → 66 次正式训练 → 通常 66 份最终选定的策略 checkpoint**；每次中途保存的多个 checkpoint 不另算新实验。没有 C2、D2-3pass、M1/M2，没有全家族×四骨干×全目标的笛卡尔积。

若追加第 11.2 节的 S 联合 latent 四格，是额外 4 个配置／12 次正式训练，总计 26 个配置／78 次；目标网络的单独预训练若发生也必须另计。它不隐藏在本轮 66 次里。

### 10.4 训练、复用与成本约定

这些是试跑起点，正式训练前按 dev 与可行性封存；改动留下版本。各子批基线只有在数据、split、source、初始化、训练预算、目标与模块合同完全匹配时复用；否则重跑并更新成本，不能只因名字相同就复用。

| 项目 | 起点 |
|---|---|
| 输入与候选 | 同一合法事实与完整适用候选；不为省显存删除未选项 |
| 模型尺寸 | 按第 2、3 节；B 单主干，D1 小核心 384 维，D2 第五批 pin 1024 维；S 用 train-only 词表 |
| batch | 目标有效 batch 32 个真实决策，按 tokens／候选组织微批；R 统计 batch 须可微且按其合同实现 |
| 优化器 | AdamW，weight decay 0.01，gradient clip 1.0 |
| 学习率 | A head 1e-3；queries／小核心／S 3e-4；PL 的 LoRA 单独 2e-5；各配对按统一冻结协议 |
| LoRA | q/k/v/o projections，rank 8、alpha 16、dropout 0.05；其余 Qwen 参数冻结；不是全量微调 |
| 调度与预算 | 5% warm-up 后 cosine；试跑 10 epochs 上限起步，正式步数／预算按 dev 后统一封存 |
| N | 按有效决策平均；单候选不产生选择梯度，另报 n>1 与 run-weighted 指标 |
| Z-fact | train 尺度归一化 Huber＋CE/BCE，缺失 mask；按字段组平均，lambda_f=1 起步 |
| Z-latent | 固定 Qwen target＋统一辅助 q＋归一化余弦，lambda_z=1 起步；与历史旧接法分身份 |
| O | O-chain.v1：四项真实结果＋战斗终点 latent，按局／战斗分别平衡；lambda_o=1 起步；缺失逐项 mask |
| R | sketch16-v1，lambda_R=0.1；R0 保持同样本与模块，仅系数零 |
| seeds | 例如 1701/1702/1703；backbone、queries、head 的初始化身份分别锁定 |
| 选择 | 同一 dev 指标与 checkpoint 规则，不按 test 或每个 seed 重新挑超参数 |

只对实际执行且相应目标合格的分支计算 Z/O。同主体目标比较保持同一 N 样本，不只挑后继齐全或终局完整的简单记录。对象条件事实头不得绕过 Y 重读原局面。没有目标用 mask，不填零；源数据本身仍须满足其准入合同。

R 普通梯度累积不等于更大统计 batch；完整候选 softmax、O 的按局加权也不能被微批实现悄悄改变。先用工程检查验证这些边界，再算科学训练次数。

三个 seeds 是全部格完整执行的基准计划，可以逐批完成后决定后批是否仍值得投入。若预算只允许单 seed 筛查，必须明确标探索：例如 22 格各 1 seed，再对预先定义规则选出的 6 格补 2 seeds，共 34 次；此时只有 6 格具备三 seed 结果，不能报告“22 格全部验证”。筛查与补跑都不能看封存 test。

GPU 卡型、实际 token 长度与吞吐未知时，只能给运行次数，不能据此承诺小时数。冻结／LoRA／S 的每次成本不同，第一子批的 profile 用于估后续工期。计入目标预编码、调参、验证、checkpoint、传输和失败。

### 10.5 每个子批的交付与停止条件

- A：四种骨干在 B、D1 上的 paired 结果、梯度范围与真实成本；不能将 RF 当从头训练小模型。
- B：预测／动作双重指标、实际目标覆盖和共同 teacher 身份；后继 loss 降但动作不改善也可形成结论。
- C：分开报告四项结果／终点 latent 覆盖，独立局与战斗数、胜率校准、数值误差和动作增益；终局不足仍可验证合格战斗目标，不伪称全项完成。
- D：表示方差／有效秩／事实 probe 与策略结果；不以“分散了”代替有效。
- E：D2 两遍信息流、梯度、成本与 N/Z 差值；不从共享权重推断更强。

每批报告配置完成数、独立局数、三 seeds 波动与按局配对区间。全部批次使用同一个封存 test，最终候选与协议冻结后统一评；中途只用 dev，不能每批看 test 再改变下一批。允许得出“数据不足以区分”或“复杂目标暂无收益”。

## 11. 后续成组实验怎样接上

### 11.1 首轮已覆盖的目标比较与下一步

P07/P13/P16/P17 已是 D1-PF 上 Z-latent off/on × O off/on 的四格；P03/P15 已覆盖 B/C1 的 N／N+Z-latent。它们属于首轮，不在后续预算重复计数。

进度／HP／主动牌数已进入本轮 O-chain。后续可对四项结果、终点 latent 分别消融，或在有严格合格比较对时增加 O-preference；每个新增配置另计次数与成本。结果预测不等于已经用结果直接训练动作偏好，更不等于 RL。

### 11.2 编码共同学习与防坍塌：单独做有解释力的对照

首个联合 latent 候选可在 D1-S-M0 上定义：当前编码器 `G=C∘E`，同一套 G 编码真实 O_next；预测端从 Y 的固定摘要经 q 预测 G(O_next) 的对应摘要；MSE 两侧均按已声明规则反传。不要一边写“联合”，一边把目标侧永久 detach 却不说明。

为保护可核查内容，保留相同的少量 Z-fact，并在实际后继编码摘要上接同类事实读出；后者是**信息保持任务**，明确记为 Z-latent 的训练配方组成，不能藏进 R 名称。事实头只看摘要，不绕过它读原文。此处是待实施候选，与冻结 teacher 路线分开注册。

最小 2×2 配对为：

| | R0 | R-VC |
|---|---|---|
| N+Z-fact＋相同实际状态信息保持任务 | 联合实验基础 | R 的基础作用 |
| 同上＋Z-latent 联合 MSE | latent 目标增量 | latent 与 R 共同作用 |

这四格使用 no-Qwen 的联合 G，不复用首轮的冻结 Qwen teacher。它们在首轮 22 格之外，新增 4×3＝12 次策略训练；若另有目标预训练，继续单独记账。四格保持模块、数据、目标读出和梯度合同一致，关闭目标仅设其系数为零。R 在这一组作用于可训练的实际状态编码摘要，当前与后继按相同身份去重的统计规则处理；不可直接套用首批“只在当前 W”而不记录变化。

这组有助于观察坍塌与任务表现，不提供全分布恢复证明。固定／EMA teacher、SIGReg 若要比较，应另做最小配对，不在这四格里偷偷一起更换。没有必要预设联合训练必然失败，也不以 N 的存在保证它一定不丢重要后果。

### 11.3 隐式不确定性：主体固定，只换一种预测约束

先选择一个有独立信息保持依据的固定 G，比较普通 latent MSE 与同 G 的固定非线性特征 MSE；锁定归一化、维度、读出容量与预算，说明仍未完全匹配的差异。有限随机特征有盲区，不宣称完整分布可辨识。

若需要更直接检查联合分布，在相同主体上另比训练期联合后继解码；评价同时看后继 NLL、校准、联合关系、动作质量和额外成本。对比／去噪作为替代候选，不要求全部实现。工程随机小例子可用于检验平均碰撞和联合关系，但绝不计入人类模型科学成绩。

### 11.4 记忆与新结构

| 问题 | 最小追加比较 | 前置条件 |
|---|---|---|
| 外挂记忆是否保存有用过去 | B-M1-GRU256 与同结构独立训练的每步 reset | 连续人类序列、正确 burn-in／恢复 |
| 持续世界是否有用 | D1-M2 与同更新器每步重置的控制 | 真实动作—后继边界、状态更新 runner |
| B/C1 的不同后继目标 | 首轮 P03/P15 已安排 N/Z-latent；后续可加 Z-fact | 同初始化／mask／数据；新目标另计配置 |
| 后果 tokens 数是否值得 | 同一个 C 单主干，K1 对 K32 | 固定主干深度／因果规则／末尾读出／目标；报告新增容量与计算 |
| 同一主干多一次评估是否值得 | D2-2pass 对 D2-3pass | 同一冻结的 F/bridge/mask/输入配方，各自训练 |
| 骨干适配与训练范围扩展 | 首轮 B/D1 已安排 PF/PL；后续才加全量或部分解冻 | 不把新 train_scope 冒称原 PL |
| 预训练与随机控制扩展 | 首轮 B/D1 已安排 PF/RF；字面权重重排须另列 Shuffle | 同 tokenizer／架构并明确破坏哪种结构 |

M2 reset 控制仍保留明确提供的上一真实动作和当前观察；它隔离的是更早的持久状态。M1 与 M2 系统互比还改变状态容量、更新器和接法，需报告这些变化，不能只给两个名字后称作纯记忆类型因果结论。

C2、D2、M1/M2 不必等 D1 赢了才能研究；它们需要对应问题、接口与预算。每次追加实验先写清比较对象和停止条件，不把四轴做完整笛卡尔积。

<a id="evaluation"></a>
## 12. 怎样判断模型真的有用

### 12.1 五层评价，各自回答自己的问题

| 层次 | 主要指标 | 能说明什么 |
|---|---|---|
| 行为模仿 | NLL、Top-1、MRR、Top-k | 在人类访问过的分布上像不像人 |
| 动作合理性 | 专家可接受动作率、严重错误率、标注分歧 | 是否选择合理，允许多个好动作 |
| 表示与预测 | 字段误差、后继 NLL、校准、事实探针、有效秩、动作敏感性 | 内部保留了什么，预测是否正确 |
| 工程与成本 | 超时/OOM/执行拒绝、恢复失败、每决策延迟、训练总耗时 | 系统是否可用、花多少钱和时间 |
| 真实策略 | 独立完整打局的胜负、进度、阶段 HP、达标后的出牌效率 | 模型自己连续选择后实际怎样 |

首批没有合格专家 Gold 时，以预先固定的留出行为 NLL 为筛查主指标，并同步报告 Top-1；不能将它叫作最优动作率。若 Gold 成立，主要决策质量看可接受动作率及严重错误，Gold 的抽样、加权与规则需提前冻结。

候选只有一个的步骤单列；主要选择表现看 n>1，并保留全量结果。随机均匀选择的 NLL 为 log n，候选数不同要分桶。每局平均与全部决策平均同时报告，避免长局掩盖短局。

### 12.2 Z、O、R、M 各自怎样验

Z 先比三个便宜基线：照抄当前事实、忽略动作、按训练条件统计给常见答案。大量字段一步不变，低误差可能来自“什么也不预测”。单独看变化字段、决策界面切换、稀有严重后果和对象绑定。

概率校准的意思是：在模型报约 70% 的合格事件集合里，实际频率是否接近 70%。用 NLL、Brier、可靠性图及分层指标；不能把动作 softmax 的 70% 当成胜率。有限稀有事件给宽区间，不宣称已经精确校准。

R 看跨样本方差、有效秩、维度冗余与 slot 重复，再用独立 probe 检查事实能否读出。probe 只在 train 拟合、dev 选择、test 检查；探针读得出不代表原评分器真的使用，还要测动作选择和受控输入扰动。

M 看自然历史依赖、距离曲线、独立 reset 控制与工程恢复。乱序／替换记忆是额外扰动诊断，不替代正常独立训练比较。若人为遮住当前可见事实，只能报告人工缺失任务结果。

O 看胜负／到达概率校准、进度／HP／计数误差、可比偏好对数量与分层表现。没有效率比较资格时只报计数预测；终局 label 的次数不等于独立终局数量。

### 12.3 最低机制检查

1. 候选顺序重排只使输出相应重排；其他候选不串扰。
2. 词序、对象归属、历史时间有表达机制；候选外部绑定 ID 不成为排序捷径。
3. D 的公共当前 W 不依赖当前候选；T／评分没有原始局面非法旁路。
4. 真实后继、终局标签只进入训练目标；辅助解码器不能泄漏未来到在线路径。
5. PF/PL/S 的梯度范围正确；B/C-PF 的 query、D2-PF 的 query／bridge 在正常训练样本上收到有限有效梯度，冻结主干不更新；R 路径不能误 detach。
6. S 不依赖 Qwen 权重、tokenizer 或隐藏 teacher；缺失目标 mask 真正生效。
7. 候选试算不写记忆，真实事件不重复吸收，跨局清零与恢复一致。
8. cache 与无 cache 在声明容差内相符；候选分块仍计算完整排序目标。
9. B/C 默认只注册一个主干实例；独立分支与共享前缀打包的输出、输入 query 梯度一致；候选位置不改变原始分数。C1-N／匹配 B-N 同图同参，C2 末尾读出可读取全部本分支后果前缀。

这些是后续实现验收要求，本轮没有以文档检查冒充模型测试已通过。

### 12.4 统计比较与泛化

按独立局或更高的泄漏关联组做成对 bootstrap，而不是把同一局几千步都视作独立样本。报告每组数量、配对差值、置信区间，以及三 seeds 的优化波动；三 seeds 不是三份新测试集。

小样本算法比较需要稳健汇总与区间，不能只挑最好 seed。相关评估研究提供方法参考；本项目整局聚类是针对人类轨迹相关性的协议选择。[Agarwal 等，2021](https://arxiv.org/abs/2108.13264)

切片至少包括决策 family、角色／难度／版本、玩家、候选数、输入长度、罕见事件。未见玩家或新版本是不同泛化问题，单独标识。只在预定少数主要对比上做确认性分析，其余标探索，避免全体两两检验后挑显著结果。

对少数代表模型可用 train 的嵌套 25%/50%/100% 整局子集画学习曲线，dev/test 固定。数据增加仍改善，支持补覆盖；训练很好而 dev 差，检查过拟合；train/dev 都差，先查输入、标签与优化。不能用很少几个容量点宣称发现双下降。

## 13. 成本怎样算，避免只看参数量

| 模型 | 一次真实决策的主要工作 |
|---|---|
| A | 每个候选都读局面＋动作；合法前缀复用需另实现验证 |
| B/C1 | 一个 T_BC 共同处理一份观察、全部动作和各自读出；密集 packed attention 仍有平方成本，不能从共享输入推断实际速度 |
| C2 | 同一个 T_BC 的每个动作分支多放 K 个后果 tokens；序列变长，无默认额外 decoder |
| D-Simple | E 读局面／动作；候选更新是小 MLP |
| D1 | E 与 C 共享当前整理；每候选只运行短 slots＋动作的 T |
| D2 两遍／三遍 | 共享 F，但分别有 1+n／1+2n 次概念调用；每遍长度不同 |

A/D-Simple/D1 的普通 PF 路径可以预计算固定 E 特征；token features 或 KV 比 pooled 摘要更占存储。B/C-PF 的 query 在训练中改变，最终 h/Y 不能预计算后永久复用；候选因果前缀若完全不依赖 query，可在精确 token、位置、mask、权重、精度及无随机失配的条件下探索 KV 复用，但须保留 query 路径梯度并与无缓存参考比较。默认训练先使用无缓存参考，不假定现有 backend 已实现这些优化。PL/S 更新主干时不能跨更新复用旧激活。

一个 Transformer 是权重／结构计数，不等于一遍低成本计算；一个密集大 forward 加 mask 也不保证跳过被屏蔽 FLOPs。B/C-PF 即使可训练参数很少，仍有穿过主干的 query 梯度计算与激活开销，不能沿用旧“小 J 反传”的显存、耗时或特征缓存估算。M1/M2 推理状态可能很小，序列反传激活仍可能很大。

至少记录：输入实际 token 长度与候选数；加载与预编码；数据等待、前向、反向、优化、保存、dev；GPU allocated/reserved 峰值；新决策 tokenize、各网络、传输、排队、执行 Receipt；持久状态字节与恢复延迟。

CUDA 用同步或正确 events；warm-up 与正式样本分开。报告 p50/p95，足够数据才报 p99；按长度×候选数切片。冷启动、驻留新输入、完全缓存命中和静态动作缓存分开，不拿缓存命中代表新局面延迟。

总训练成本包括预计算、调参、正式三 seeds、OOM／失败重试、checkpoint、评估、存储传输。总工期使用实测吞吐外推，不编云价。主报告画“可接受动作／严重错误—延迟”和“质量—总训练 GPU 小时”两条前沿，并报每千次完整有效决策的成本及失败分母。

### 13.1 本轮实际预算口径：10 万条记录与 Modal 30 美元

10 万指记录，绝不是局数，也尚不保证都是去重后合格决策。先分别盘点 N、Z、战斗 O、整局 O 的覆盖；按同局／同源关系分组，完整与不完整局不混成同一种资格。记录不足完整局不妨碍合格 N/Z 或已结束战斗的 O。

2026-09-18 对本地候选源码与 Modal 账号做了只读核对：`ModalTarget` 默认 L4／3600 秒；wrapper 单容器、零常驻、零代码重试，未显式配置 CPU／RAM。`spireagent-b` 环境存在，查询其 App 列表为空；这不是已经部署并测量过的 GPU Worker。30 美元是用户提供的额度及官方 Starter 月额度，未核实当前剩余金额。没有启动任何训练。

完整研究仍是 22 配置×3 seeds＝66 次；本月额度启动批与完整研究分开。成本不能由记录条数直接推出，必须量每配置包含所有候选的真实训练吞吐，以及预编码、数据读写、验证与失败。当前第一阶段的成本测量和预算边界见[S0 第一阶段计划](S0_STAGE1.zh-CN.md#cost)。后续大规模预算必须用实际吞吐重新计算，不沿用两头训练或阶段小样的费用。

## 14. 什么之后才可以讨论多步规划和 RL

当前目标是人类监督候选评分。即使结构有 T、训练有 Z、D2 有三遍，也不自动拥有多步规划。

多步想象还需要：预测状态可以继续输入、误差可控；想象分支的动作集合有可靠来源；奖励、终止和状态边界清楚。平台只处于真实当前状态，不能直接给未发生世界的权威候选。

可先用真实人类动作序列做 1/2/4 步诊断，明确这是固定动作压力测试，不是模型自主搜索；偏离后续真实状态时，原动作未必在想象状态合法。一步统计摘要也未必属于真实状态编码空间，不能因形状相同就直接反复喂 T。

后续路线是：监督 N/Z/O → 明确价值与结果合同 → 独立离线 RL 比较 → 有授权的新策略交互数据 → 达到证据要求后研究短想象训练。A/B 可长期使用直接策略或 model-free RL，不因没有世界预测被淘汰。真实 AI 打局可作为独立评估；其轨迹不自动回流当前人类训练阶段。
