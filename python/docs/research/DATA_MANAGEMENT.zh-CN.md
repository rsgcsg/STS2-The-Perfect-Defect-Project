# 决策、数据集与实验：统一数据管理设计

日期：2026-09-18。状态：第一阶段的目标设计，尚未全部实现。
当前 [ADR-0010](../../../docs/adr/0010-dataset-curation-and-continuous-recording.md)、
现有 schemas 与 owning 源码继续约束运行行为。本文提出的可调整普通隔离、用途转换和统一归档，
须在对应实现／合同 PR 中明确更新 ADR 与消费者；本次文档导入不让旧入口自动放宽。
实施范围见 [S0 第一阶段](S0_STAGE1.zh-CN.md)。

第一阶段已实现的具体范围见 [S01 验收](evidence/S01_2026-09-18.md)：精确包内决策索引、
不可变 train/dev 分配及 run/decision 两种协议、输入和模型溯源、阶段产物的个人归档与恢复。
可调整协议目前用于 S01 的 train/dev 工程划分；普通 test 配对及 Gold 仍执行已有保守保护，
没有把所有评测入口同时放宽。用途转换、战斗级隔离及全对象批量归档仍是后续目标。
新网页代码已对齐公共服务，但未在本轮更新生产服务。

## 1. 四个容易理解的对象

原始包是原件；决策库是可查询目录；数据集是固定书单；实验记录怎样使用这些书单。
一条决策是最小管理单位，固定数据集是实际训练／评测输入，真实局与关联组是可选隔离依据。

| 对象 | 保存什么 | 能怎样变化 |
|---|---|---|
| 原始证据／决策 | 原生发生身份、内容、来源与真实因果引用 | 原始事实不改写；质量说明追加 |
| 数据集版本 | 固定成员及内容身份、规则、用途、质量快照、父版本 | 草稿可改；发布后成员变化产生新版本 |
| 实验／分配 | 使用哪些固定集、内部train/dev成员、隔离规则与检查范围 | 开始运行前固定；协议改变另立版本 |
| 运行／模型／评测 | 配置、输入、权重、实际使用、报告和证据 | 暂停恢复保留Run；新模型／报告有新身份 |

数据集不是一个独立数据库。多个集共用决策目录，通过成员关系引用原件；
不要为了十二配置复制十二套包。动态筛选可保存，但训练开始前固定其当时成员。

## 2. 训练、验证、普通评测与 Gold

界面用“训练集”和“评测集”，评测集显示“普通”或“封存 Gold”。后端现有
`purpose=training/test/gold` 仍保留明确枚举，不在这一文档中更改 wire/schema。
训练集内部的 train/dev 是实验分配，不强迫用户另建第四种数据集。

- train：更新模型参数、拟合词表／尺度。
- dev：开发、选参数、查失败；不自动称独立终评。
- 普通test：固定模型后评测，可以授权查看具体错误；反馈用于开发后需记录暴露，
  再次报告时不能继续冒充未见确认集。
- Gold：额外保护的评测材料，不自动有专家答案。封存状态与标注状态分别显示。
  专门的标注／评测权限可以读取必要内容，普通训练／导出不能读取。

封存限制使用，不禁止改显示名、标错、授权标注、派生新Gold版本、Gold合并或归档。
从Gold新版移除一条决策，不自动释放它及既定关联范围的保护。历史下载无法收回，
曝光历史显示已核对／存在暴露／未知，不以一个锁图标保证绝对秘密。
普通test未来转训练的目标流程是显式派生、记录暴露与用途转换、给相关模型更换独立测试；
当前训练祖先拒绝会阻止直接转换，需版本化的准入合同与忠实回归，不能仅改标签或绕过祖先检查。
Gold不采用这个转换流程。

## 3. 可调整的普通评测隔离

“同局不能测试”是现有保守默认，不是所有实验的数学定律。
普通实验可选择下表协议；允许的结论必须随结果显示。

| 模式 | 最小隔离单位 | 可解释的评测 |
|---|---|---|
| decision | 同次发生及其重复副本 | 未训练过的决策，可能见过同局其他部分 |
| combat/segment | 可信战斗／连续片段边界 | 未见战斗／片段，可能见过同局其他部分 |
| run（推荐默认） | 已知整局与配置的关联组 | 未见局评测 |
| 后续player/version | 明确玩家／版本分组 | 特定跨域泛化，首阶段不做完整选择器 |

第一阶段至少明确并实现 decision/run；没有可靠战斗边界时 combat 显示暂不支持，不能按时间猜。
协议在划分和读结果之前固定，不能因某种模式成绩更好就改名“独立测试”。
始终检查真实发生别名、模型全部训练祖先及实际输入／目标依赖。相同输入指纹不是同次发生身份，
可按固定协议分组或报告，但不能把已知重复副本当独立样本。
历史窗口、父子选择、后继、O终点若跨集合被实际读取，须按依赖使用情况阻止或标记相应暴露；
不能仅比较当前行ID。放宽划分粒度也不把统计独立单位变成每一行，相关局／组仍用于区间与计数。

Gold第一阶段继续整局／传递重复关联保护；不增加一个通用“关闭Gold隔离”开关。
普通评测粒度与Gold保护粒度分别记录。UI显示选入Gold的条数和保护波及的组／条数。
新导入数据增加关联时，重新检查受影响实验／预留；未知身份不能显示隔离已通过。

## 4. 身份、索引与固定成员

已有 occurrence key 为 hash(session_id,native_run_id,decision_id)；顺序号和显示名不是身份。
同次操作在多个原始包出现，可有多个source alias；内容冲突必须明确诊断。
不同局相同可见输入可以保留多个观测；decision fingerprint只用于输入重复／隔离判断。

在现有存储／业务账中补足以下关系（逻辑名，不宣称函数或表已存在）：

```text
decision occurrence → 内容版本、run、原生顺序、摘要、资格
decision_sources    → source_id、准确记录位置、证据引用
dataset_members     → dataset_version、occurrence、内容版本
allocation_members  → allocation_version、成员/组、角色、protocol_version
quality_events      → occurrence、标记、原因、操作者、版本
usage               → 输入版本、Run、模型祖先、评测/下载、用途
```

精确source包含关系不能只通过 source→run→所有decisions 推断。
完整状态／候选／因果证据保存在可信对象或分片，索引保存定位与必要摘要；一条记录不必一个文件。
数据集成员清单保存为不可变产物，数据库投影可重建并与成员摘要核对；不信任客户端提交的行内容。
成员清单应绑定源版本、数量／内容校验、质量版本、用途和执行协议，避免每次查询从头重投影全部包。

## 5. 数据集操作与生命周期

| 操作 | 规则 |
|---|---|
| 相同决策进多个训练集／普通评测集 | 可以；实际训练与评测配对按模型历史及协议检查，不把重叠评测集当独立重复实验 |
| 本次不选 | 只影响选择草稿，不写全局质量问题 |
| 标记／排除／恢复 | 追加质量事件；新选择使用新快照；原始内容和旧集不暗变 |
| 子集／新增／移除 | 新固定版本，保留原始顺序及依赖缺口，不虚构跨缺口链 |
| 合并 | 同用途合并并去重；冲突不可按最后一份覆盖；Gold只与Gold合并且保持保护 |
| train/dev分配 | 固定在实验中；合并集发生分配冲突则新协议显式重分，不静默沿用冲突角色 |
| 归档／恢复 | 修改管理元数据，默认列表收起／恢复，内容ID和保护不变 |
| 清缓存 | 只清可重建且未占用派生物，按引用和身份执行 |
| 永久删除原件 | 独立保留策略、引用与审计流程，不等于归档按钮；第一阶段不实现普遍硬删除 |

Gold来源和保护账先确定，再建立普通训练／测试；不要先将全部内容暴露为训练总集后宣称重新封存。
固定普通实验可复用已有数据集；一键生成训练／测试／Gold只是便利操作，不是每次必走的仪式。
原始条目允许归档目录项，但归档不是质量排除，不会让现有训练运行少读一条。

## 6. 归档贯彻到所有阶段对象

source目录、数据集、已结束预览／任务、实验、Run、模型、报告统一支持当前／已归档筛选、批量归档与恢复。
决策层可收起浏览项，但不改变质量／成员；Gold的可见性仍受专门授权控制。

- `archived_at/by` 等管理信息留在业务服务，不能为改显示状态重写不可变artifact。
- 有共享对象时显式区分个人列表隐藏与项目归档；权限在服务端检查，不能成员一点击让所有人失去入口。
- 运行任务不能靠归档冒充停止；明确取消／暂停后核对真实执行状态，保留可见费用与未知状态。
- 当前安装模型归档不等于卸载或停止；设备状态另行管理。
- 归档不释放存储、不释放用途预留，不隐藏被历史模型引用的路径；搜索可包含已归档。
- source、成员目录等可重建索引与Gold／质量／用途／归档／任务业务账分开；后者备份恢复不可省。

## 7. 用户实际走的流程与 UI

```text
采集记录（上传／核验／索引）
 → 决策视图（筛选、全选结果、详情、标记）
 → 保存数据集／分配（已有版本或新建，先预览再固定）
 → 实验（选数据版本、隔离方式、S01、执行地点）
 → 训练与dev报告 → 模型导出 → 目标机器新输入评分
```

侧栏保持采集记录、数据集、训练与分析、模型与评估四个主要入口。
决策库可作为采集记录／数据集详情里的视图，不再制造大量平级页面。

| 页面 | 最先显示 | 操作与服务映射 |
|---|---|---|
| 采集／决策 | 上传与索引、真实完整性、来源、发生时间、动作摘要 | 分页索引查询；侧栏详情读准确决策；全局标记与本次不选分开 |
| 数据集 | 已生成列表、用途、版本、条数／独立组、质量覆盖 | selection服务、成员／版本差异、合并／子集；预览任务次要展示 |
| 训练与分析 | 一张实验卡串数据／配置／进度／费用／报告 | 同一TrainSpec与provider任务服务；恢复精确checkpoint |
| 模型与评估 | 固定模型、支持范围、backend、报告、本机状态 | 同一export/load/score协议；加载／评分／原生运行分别显示 |

各处归档行为一致。页面切换不启动重新处理，不整页闪白；只更新变化状态，保留筛选／选择／滚动。
网页、CLI、Workbench调用同一业务服务；Hub持有共享用途／权限账，本地是获授权的执行与缓存节点。
本地离线时不能猜最新Gold状态；固定工作包与授权期限由共同协议管理，不建第二份用途真相。
真正取数据／开始训练／评测／导出时重新检查，缓存列表不等于缓存授权。

## 8. 模型产物与效率验收

模型包至少绑定 graph、完整训练配置、backbone/tokenizer pin与实际校验、serializer/pooling、
所有可训练权重、特征计划、dataset/allocation、训练来源、框架／精度、支持范围和适配器版本。
checkpoint另存优化器／RNG／采样位置／步数；推理包不带原始训练／评测数据。
同一基础权重可共享下载，但必须校验身份；PF/RF/S与不同tokenizer不串缓存。

列表查一页摘要，详情定位一条及必要上下文；训练顺序／分桶读取批量分片。
首次上传可逐包核验，后续选择复用可信索引；缓存损坏重新核验，不能为了快取消内容与权限检查。
按冷索引、热查询、预览、固定成员、物化、训练读取分别测耗时、读取字节、峰值内存、命中率与恢复重做量。
一万／十万条只是测试规模，不是已有吞吐保证；先用小样消除错误，再扩大容量。

成功必须能双向追溯：模型→实验→数据集→决策→原始证据，决策→成员集→模型／评测使用。
并验证重复上传不增真实数量、协议跨入口一致、Gold并发预留、标记后旧集不变、归档恢复、
索引重建和任务中断。工程fixture不冒充人类／科学证据。


## P1 每次实验分配和模型血统使用（2026-10-27 用户决定）

日常录制入原始数据/P1 轨迹池，不贴永久 TRAIN/DEV/TEST 标签。每次实验从池中选择
整局分组和角色、模型阶段与父阶段、权重规则，沿原 Curation/Snapshot 冻结。
`CurationLedger` 同一 SQLite 的 `curation_p1_experiments`、
`curation_p1_experiment_runs` 与 `curation_p1_model_uses` 保存计划、角色/权重和实际使用；
不是第二个用途 owner。旧 claims、使用与 414 原文件保留。

新实验允许跨次复用训练局，不继承旧的全局 DEV/TEST 锁定。考试局必须未被本模型和
全部前辈训练，且与本次 TRAIN 不重叠；已知重复/亲缘按原分组处理。按 actual use 而非
仅冻结计划计算训练曝光；词表构建前原 prepare 就记使用。旧模型须由已核实的原
Snapshot/operation 绑定父阶段记录，缺失历史拒绝。模型父子声明不能替代真实初始化来源；
跨新数据集继续训练还受原训练实现限制，见[操作与当前边界](../RECOUNT-SOP.zh-CN.md)。

权重是每次实验配置，定义变化才重新展示并确认；同定义的批准可供后续明确 freeze
调用复用。pool/preview 不批准、不冻结；未知操作先查原请求，不盲重发。
本轮暂不额外永久保留公共考试组：小池优先保留训练弹性，血统隔离已满足当前硬要求。
