# Native logical publication profile v1

This is a model-neutral **fixed target**, owned by the
[versioned JSON contract](../contracts/native-logical-publication-profile-v1.json).
It is not a dynamically selected advertised subset. The input profile remains
`native-logical-v1`; the publication profile is
`native-logical-publication-profile-v1`. The profile requests full-reference
publication of the four canonical eager fields and every listed seam at exact
version `1` with `complete_at_seam` coverage.

The guarantee is **full reference for these defined publications**. It is not
complete native game coverage, all L01–L64 qualification, Human origin, causal
transition proof, research admission or G2/V1 approval. Those retained obligations
require the other native families and their independent verification. Additional
unsupported families cannot shrink this fixed target.

## Registration and failure accounting

A consumer validates this fixed target against actual advertised capabilities.
A missing, sampled, unsupported, duplicate or wrong-version required seam fails
default registration. Bootstrap-only registration cannot satisfy this target.
The public SDK derives its exported target from this one JSON authority; Platform
must not import an external model or research definition.

Actual advertisement is conditional on successful exact typed hook registration
and the native publication service's faithful source capture conditions. Merely
changing a coverage label does not establish support. One initialized game-main-
thread composition notification confirms the whole profile after every required
registration succeeds. The same validated declaration belongs to the existing
hub and is the declaration capabilities report; there is no second registry.
Previously accepted subscription/source epochs retain their original declaration.

For an eligible observed source callback, reserve its original position before
freezing public facts. Freeze complete requested public values at that callback
on the native thread, then encode/persist off-thread through the existing service,
projector, store and hub. Native/source certificate, binding, scalar, capacity,
thread, encoding or retention failure becomes an explicit original missing
position or gap. No later Current call, timer or unrelated callback fills it.
`complete_at_seam` promises this source accounting and same-occurrence full-
reference path, not that every native callback necessarily yields a valid input.
Partial/missing outcomes never become full input.

its exact eligible native instance. It grants no dispatch authority. Unrelated,
stale, hidden, disposed or non-owning objects do not become current public views.
If an eligible callback cannot be captured, its original position fails explicitly.
Callback phase/version changes require a versioned contract change.

The exact inspected source basis for the first producer is arm64 STS2 assembly
SHA-256 `9cb4f1ad8c9f284aa8fec3122ffd6d780bbf543d875c817abdd12ff63fbf12b4`.
Native APIs and faithful producer guards are validated separately; fixtures do
not establish installation, load, runtime or family qualification. This file is a
contract target before its new producer is independently accepted.

The native card inspector is assigned before its scene `_Ready`, which calls
`Close` before `Open` has supplied `_cards`. That initialization close is not an
entered information owner. Eligibility reads the actual native source field;
it does not require a successful display certificate, so an entered callback
with an unproved display still retains its original explicit missing position.

Native card `Close` leaves the current source/display tuple unchanged while the
view remains visible. Its completed display certificate remains usable only
under the same exact current-owner, visible-node and tuple checks. Close removes
navigation/hotkeys but does not disable the native Backstop. Each control's
actual admission determines the complete closing catalog; withdrawal does not
promise an empty catalog. A surviving Backstop return remains published. Only
an actually empty complete catalog yields `observed`. The native delayed
visibility/context callback publishes the real restored owner independently.

## Observation status

Status describes the actual public view and stays separate from source/event kind,
catalog completeness, native interactivity, input delivery and causal knowledge.
The existing producer vocabulary is `interactive`, `settling`, `observed` and
`visible_unsupported`.

`observed` may be a valid **complete** public frame with an empty native catalog.
The producer's SnapshotBuilder already emits it for complete no-action/non-
settling views, and the logical grid adapter emits it for native completed selection.
Consumers consume that offered public view exactly once and await an actual later
source publication when there is no action. They cannot relabel it `settling` to
invent readiness, discard its history, or infer Commit, success, task end or a
causal successor. A terminal event kind/native game-over surface is distinct;
this profile does not manufacture an Observation status named `terminal`.

## Conformance and real path gate

The [golden fixture](../contracts/fixtures/native-logical-publication-profile-v1.json)
binds the exact contract digest and includes fixed-target/negative registration,
original missing/capacity positions and complete no-action `observed` examples.
Tests must use the same public contract for producer/SDK/app acceptance.

Source tests additionally falsify early capture before Native Foundation or
presentation-finalizer registration, stale/wrong instances, delayed close,
actual native clickability changes, A→B→A occurrence, burst admission and callback
exceptions. No fixture claims a real-game exposure or qualification.

The root-owned runtime canary uses exact integrated package/install/cold-load
identity and rollback, an attached real SDK Await consumer and passive source
recording. It exercises deck→inspect→closing withdrawal→deck return and reward
parent→child select/skip/defer/reroll→actual parent return/proceed. Every promised
source phase retains original ordered complete bytes/catalog or explicit failure;
no Current poll backfills history. Any missing/gap, unsupported view, unknown
delivery or wrong identity fails canary qualification. Remaining native families,
full task journeys, Human and research gates still remain.
